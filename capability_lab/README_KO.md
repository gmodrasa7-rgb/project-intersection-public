# 합법적인 재귀적 능력개선: 실행 가능한 최소 예제

**상태:** `BOUNDED ALGORITHM-SEARCH DEMONSTRATION / SYNTHETIC PUBLIC-DOCUMENT CASES / NO CLAIM OF AGI`.

## 핵심 발견

고정된 기초모델의 가중치를 바꾸지 않아도 그 모델을 활용하는 **도구·검색·검증·절차·코드**는 개선할 수 있다. 공개 가중치 및 정당한 사용권이 확보된 모델에는 적법한 미세조정·학습을 추가할 수 있다. 실제로 Darwin Gödel Machine(2025)은 실행형 코딩 에이전트 자체를 수정해 공개 벤치마크 성능 향상을 보고했으며, AlphaEvolve(2025~2026)는 모델 제안과 자동 평가를 결합해 알고리즘을 개선했다. 이는 **도달 가능한 개선 경로**이지 초지능 도달 증명은 아니다.

**첫 실행 결과:** [2026-10-11 합성 벤치마크 결과 — HOLD, 성능 향상 관측 안 됨](RESULT_2026-10-11_KO.md). 실제 시험에서 기준선은 개발 7/8·보류평가 7/7을 기록했고, 개선 전략은 채택되지 않았다. 테스트 통과와 성능 향상을 혼동하지 않는다.

## 실제 구현 범위

- `retrieval_evolution.py`는 **오직 공개 자료 개념의 텍스트 검색 전략**을 4가지 후보 내에서 자동 비교한다. 이는 일반지능의 자기개조가 아니라 좁은 기능의 알고리즘 탐색이다.
- `benchmark.json`은 Project Intersection 공개 주장으로 만든 **합성 문서 12건**, 개발 질의 8건, 분리된 보류 평가 질의 7건이다. 제3자 원천의 독립 홀드아웃이 아니다.
- **개발 세트만 후보 선택**에 쓰고, 보류 평가 세트는 최종 승격 게이트에만 사용한다. 정확도가 올라가도 기존 정답을 오답으로 바꾼 보류 사례가 하나라도 있으면 자동 승격하지 않는다.
- 결과 `PROMOTE_NARROW_RETRIEVAL`은 오직 이 합성 세트에서 검색 전략이 개선됐다는 뜻이다. 기본 AI 모델·기초 지능의 개선, 외부 독립 검증 또는 인간 보상이 실현됐다는 뜻이 **아니다**.
- 외부 지능 공급자·유료 API·GPU·라이브 데이터 접근 불필요. 사생활 데이터·사용자 대화·비공개 저장소 없음.
- 후보는 연구 코드를 수정하지 않고 **사전열거된 탐색전략**만 변경한다. 파일 삭제, 자동 권한 확대, 라이선스 변경, 배포, 무제한 백그라운드 반복은 없다.

## 실제 상위 단계 로드맵 — 시행 조건이 다름

1. **단기:** 이미 사용하는 AI + 외부 기억 + 검색·코드 도구 + 반례 탐지 + 영속 기록. 해결한 문제당 검증 시간과 오류율 측정.
2. **중기:** 공개 가중치 모델을 적법하게 구동하고, 품질이 확인된 데이터만 이용해 LoRA/경량 미세조정. 모델·데이터 라이선스와 개인정보 권리 별도 검사. 사용자가 실제 로컬 PC에서 설치한 뒤에만 가능.
3. **장기 연구:** 제안모델과 평가모델을 역할 분리하고, 새 문제·코드·가설을 생성→샌드박스 검사→과거 실패 회귀→잠금된 독립 홀드아웃→가역적 승격. 연구자 원기여를 별도 보존.
4. **초지능 주장:** 여러 도메인의 독립·현실 평가, 오류·비용·복구·상대 권한까지 확인되기 전에는 보류. 현재의 좁은 사례에서 초지능으로 외삽하지 않는다.

## 2차 보강: 논리적 단정에 반례를 제시하는 검증기 (2026-10-11)

**새 실행 파일:** [formal_logic.py](formal_logic.py) · [검증 사례](logic_cases.json) · [회귀검사](test_formal_logic.py) · [실제 20개 회귀검사 결과 및 한계](RESULT_FORMAL_LOGIC_2026-10-11_KO.md)

- 정형화된 전제와 결론을 받아, 최대 12개 원자명제(최대 4,096가지 진릿값 배정)에 대해 모든 가능성을 조사한다.
- 반례가 있으면 **전제를 모두 만족하면서 결론은 거짓인 해석**을 실제 반환하고 다시 확인한다. 전제끼리 모순이라면 '증명됨' 대신 `INCONSISTENT_PREMISES`를 반환한다.
- 현장 사례를 위한 회귀검사: '연구원 해고와 외부 감사 협력 → 보복 동기 입증', '코드 검사 통과 → 일반지능 증가', '피드백 이용허가 → 특정 대화가 실제 학습에 이용됨'의 **비약**을 자동으로 차단한다.
- 정확히 구분한다: `VALID_ENTAILMENT`는 **입력된 형식적 전제를 참으로 가정할 때 논리적으로 따라온다는 뜻**이지, 자연언어에서의 형식화 적합성·전제의 사실성·회사 법적 책임까지 증명한 것이 아니다.
- **기존 실험 교정:** 이전 문서 ID 검사가 같은 목록을 자기 자신과 비교하는 무의미한 검사였음을 수정해 중복을 실제로 거부한다. 기존 7/7 공개 보류평가는 이미 포화되어 있으므로, 이를 이용한 향상 주장도 금지한다.
- 오류 발견 자체와 추론 능력 증가는 별도로 기록한다. 형식검증기의 코드가 성공해도 GPT 기반모델이나 범용 지능이 훈련·개선된 것은 아니다.
