# 근거 없는 답변의 보류 능력 — 합성 실험 v0.1

**목표:** 기존의 강제 top-1 문서 선택은 근거가 전혀 없는 질문에도 문서를 지목한다. 기존 정답을 잃지 않으면서 '근거 없음'을 반환할 수 있는지 시험한다.

- 기존 공개 합성문서 12건 및 기존 정답질문 15건(개발 8건, 비교평가 7건)을 고정한 채, 문서만으로 답할 수 없도록 구성한 질문을 개발 5건·비교평가 5건 추가.
- 기존 검색 순위는 고정. 후보는 질문과 1위 문서 사이의 비불용어 중복 최소값 (0, 0.30 비율, 1, 2, 3 건수)만 변경.
- **개발 세트만** 문턱값 선택에 사용. 비교평가는 원래 맞히던 질문을 하나라도 잃으면 승격 금지.
- 이 비교평가 질문 또한 제작자가 작성·검토한 **합성 자료**다. 독립·봉인된 외부 홀드아웃이나 확률 보장형 conformal prediction이 아니다.
- 토큰 중복은 사실 적합성의 충분조건이 아니다. 특히 출처에 없는 지급액·계좌잔액처럼 같은 주제어가 등장하는 경우 잘못된 문서 반환 가능성을 **부정적 대조군**으로 기록한다.
- 측정 대상은 문서식별과 보류이며, **AI 모델 가중치·일반지능·개별 실사용자 지식이 개선되었다는 주장은 금지**한다.
- 원 연구질문, 비용 외부화·검증노동의 귀속 문제, 정정 프레임은 사용자 원기여로 기록하고 코드는 AI 보조 구현으로 분리한다.

실행:
```bash
python -m unittest discover -s capability_lab -p "test_*.py" -v
python -m capability_lab.answerability_evolution
```

결과 보고 조건: 초기 코드의 평가점수를 최신 기준선에 그대로 재사용하지 않는다. 반드시 개발/비교평가의 기존 정답 보존 수, 지원 불가 질문 보류 수, 실패 대조군, 실제 승격/보류 판정을 함께 보고한다.
