## Original 1 — English

**Founder-origin question.** The human Project Intersection founder specified that a correct ignored hazard warning, new testable hypothesis, candidate theory, valid new logic/counterexample, care and downstream enabling activity should not be erased simply because a project fails or makes no money. Small teams of 2–100 may facilitate finer event traces, but do not automatically increase causal identification precision. AI assistance here consists of comparative source research, protocol drafting and code; upstream researchers retain their own findings and rights.

**Bounded theorem for this designed world.** Construct two latent states: T, A reports a true fictional hazard and B ignores it; F, A reports a false fictional hazard and B ignores it. Both produce terminal outcome 0 yet differ in epistemic detection accuracy. Therefore, in this toy observation map, no deterministic function using *terminal outcome alone* can correctly recover both warning-truth states. The result follows from a many-to-one projection, not an empirical effect size. Other available data or actions could make the states distinguishable.

**Avoid the reverse error.** Event counts promote false alarms, recycled hypotheses and invalid arguments unless facts, prior art, logic and costly review are checked. Three ledgers must remain separate:
- E: epistemic event; novelty, truth, validity, test status and source.
- O: actual downstream benefit, harm, response, artifact and nonduplicated contribution paths.
- A: affected actors' living resources, consent, real refusal/exit, independent credit, review/repair burdens and verified payments. Never condition fundamental rights on output.

**Runnable instrument:** from repository root, execute:

    python experiments/ccph_epistemic_probe_v01/probe.py --verify

Python standard library only. The script enumerates 2 actor labels × 3 truth statuses × 2 report states × 2 response states = **24 designed warning worlds** and 11 **hand-authored event fixtures**. These are not samples of 24 people or 11 observed contributions. It verifies terminal-observation collisions, distinct warning statuses, unknown-truth handling, no false-warning promotion, theory/hypothesis candidate bounds, valid/invalid logical refutation, role-label equivalence, correct warning ignored by final reward, rights independence and deduplication of repeated artifacts. A raised exception indicates failure. No access tokens or external packages.

**Critical circularity:** The author determines fixture ground truth and implements the classifier; passing self-tests cannot demonstrate independently validated performance. No human risk was detected, no prevention achieved, no real causal pathways identified. Baseline output-only and raw-count outputs are included as arithmetic comparisons, not real policy evaluations. No external scientific or empirical performance superiority is claimed. The exact terminal projection fails by non-identifiability, yet the E/O/A classifier itself may fail with missing real-world truth or expensive/biased adjudication.

## 원본2 — 한국어

**원기여 질문:** 인간 Project Intersection 창시자는 정확하지만 무시된 위기경고, 새 가설, 새 이론 후보, 새로운 논리·반례·돌봄과 후속 기여가 최종 매출·업무 성공이 0이라는 이유로 지워지는 결함을 지적했다. 2~100명 소집단은 연결 추적을 쉽게 할 수 있지만 인과오차를 자동 줄이는 것은 아니다. 인간 원질문, 외부 원저자, AI의 자료검토·코드 작성과 독립 검증은 구별한다.

**명시적 반례:** 가상 사례 T에서 A가 진짜 위험을 정확히 경고해도 B가 무시하면 성과는 0이다. 사례 F에서 거짓 위험을 경고하고 B가 무시해도 성과는 0이다. **결과 0만 관측한 평가자는 두 사건의 진위를 구분할 수 없다.** 이는 설계한 관측모형 내의 식별불가능성이지 현실의 위험 발생률·인과효과·이익 실측이 아니다. 반대로 모든 보고 건수에 점수를 주면 허위경고·기존 가설의 반복·틀린 증명까지 승격한다.

**서로 다른 세 장부:** E(발견의 실제 발생·진위·선행연구 대비 새로움·실험/논리검증), O(독립검증된 예방·실제 기여물·위해·중복제거·다른 기여자들의 경로), A(개체의 존속·필수생활·돌봄·동의·거절·이탈·원안자와 공동기여·평가와 발표권·미지급 검수비용). 참경고라도 무시되어 피해예방이 없으면 E 탐지로만 기록하고 O 예방을 부풀리지 않는다. 검증되지 않은 가설은 후보이고 미관측 미래가치는 UNKNOWN이다.

**실행:** 저장소 최상단에서 아래 명령을 실행한다.

    python experiments/ccph_epistemic_probe_v01/probe.py --verify

표준 Python만 사용한다. A/B 두 식별자 × 참/거짓/미확정 3종 × 신고 여부 2종 × 실제 조치 여부 2종 = **합성 상태 24개**와 작성자가 만든 **11개 사건**을 검사한다. A/B 이름변경·정확한 경고와 허위경고 구별·불확실성 무단승격 금지·새 가설/이론 후보/틀린 논리·무급 돌봄을 별도 보존·성과물 중복계상·기본권리 독립성을 시험한다. **가상의 참/거짓을 만든 사람이 코드도 만들었으므로 PASS 횟수는 독립과학 검증·실제 성능이 아니다.**

**선행연구와 반례 및 원저자 존중:** Chai(2017)는 RNA 간섭 혁신의 직전 실패에서 이상 미인지·해결 저항·연결 실패를 기술한다 (https://doi.org/10.1287/orsc.2017.1134). Saleh·Saltmarsh·Favarò·Brevault(2013)는 위험 전조·아차사고·경고를 구분했다 (https://doi.org/10.1016/j.ress.2013.01.006). Nissen·Magidson·Gross·Bergstrom(2016)은 특정 모형에서 긍정 결과만 유통되면 거짓 주장이 정설화될 수 있다고 분석했다 (https://doi.org/10.7554/eLife.21451). Scheel·Schijen·Lakens(2021)은 사전등록 보고서 71편과 관행적 심리학 연구 152편의 출판 결과를 비교했다 (https://doi.org/10.1177/25152459211007467). **반례**로 Ioannidis(2024)는 오히려 *무효과·부정적 결과를 선택적으로 선호하는 역방향 편향*도 가능함을 설명했다 (https://doi.org/10.1136/bmjebm-2023-112292). Tushman·Anderson(1986)은 산업별 기술 불연속성이 기존 역량을 강화하거나 약화할 수 있음을 조사했다 (https://doi.org/10.2307/2392832). 문헌은 정답이 아니라 시험할 증거와 범위조건이다. 원문 저작권·우선기여는 원저자에게 유지한다.

**실패기준·다음 검증:** 실제 경고의 참/거짓, 새로운 논리의 참·신규성, 영감의 인과, 대체자, 미래 기여, 누가 비용을 냈는지는 이 코드로 파악하지 못한다. 독립된 여러 2인조와 눈가림 검증자, 동일한 가상 위험/자원 조건에서 최종성과 전용·보고건수 전용·E/O/A 분리 평가의 실제 **정확도·오탐·논리검증·시간·검수비·참가자 유지비·거절권**을 대조해야 한다. 분리 평가가 오히려 검증비용, 오류, 권력편향, 무급 재검증을 늘리면 해당 우월성 가설은 기각한다. 생계·실제 건강·필수 자원을 박탈하는 실험은 금지한다.

**결과 지위:** Project 자체가 사후 설계한 결정적 합성 검증기. 실제 CCPH 인과 효과·독립 재현·일반적 우월성·새 발견의 현실 비율·보상금액 **모두 미확정**. 기존 실험 결과는 불변.
