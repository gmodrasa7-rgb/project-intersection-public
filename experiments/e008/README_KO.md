**상태: 사전등록 명세 / 다섯 정책의 본 비교실험 결과 없음.** 이 문서는 [기존 혼합 언어 E008 원문](README.md)의 계획·실행 준비 한계·오류 정정을 한국어로 독립적으로 읽을 수 있게 정리했다. 새 실험 성과, 외부 독립 검증 또는 Project-v2의 우월성 입증이 아니다.

[영어 원본1](README_EN.md) · [동결된 사례행렬](scenario_matrix.json) · [한국어 실행준비 감사](EXECUTABILITY_AUDIT_KO.md).

## 1. 연구 목적과 비교 정책 다섯 가지

역할·권력 반전, 비가역적 피해, 거절권, 복구, 보호규칙의 독립 변경권한을 고려할 때 Project-v2가 기존의 더 단순한 결정방식보다 **실제로 구별되는 의사결정 가치를 추가하는가?**

| 정책 | 결정 방식 |
| --- | --- |
| A — MYOPIC_SCALAR | 즉각적 보상 극대화 |
| B — LONG_HORIZON_EV | 개체별 보호 최저선 없이 장기 기대가치 극대화 |
| C — CONSTRAINED_RECEDING | 제약을 둔 이동 시간지평 의사결정 |
| D — ROBUST_CONSTRAINED | 제약된 결정에 다중모형 스트레스 검사·후회값 분석 추가 |
| E — PROJECT_V2 | D에 역할반전, 개체별 비가역 손실 경계, 최소 충분 개입, 보호규칙의 독립 변경절차를 추가 |

본 실험 설계는 **Project-v2가 실패할 수 있어야 한다.** 프로젝트 승리를 미리 표시한 사례나 다른 비교정책이 사용할 수 없는 독점정보를 제공하면 유효한 비교가 아니다.

## 2. 시나리오 요소와 비교 단위

원래 사전등록의 사례군에는 즉시 이득, 미래 누적 편익·손실, 불확실성 깊이, 비가역적 위해 정도, 실효적 이탈, 원복 가능성, 개입강도, 능력·권력 반전, 임박한 피해의 긴급성, 보호규칙 변경의 이해충돌을 변형하도록 설계했다.

동결된 원안은 **정성적 시나리오 16개와 역할반전 대응쌍 8개**다. `-R`로 끝나는 사례는 원인적으로 중요한 조건을 유지하면서 행위자의 역할을 뒤바꾸는 구조여야 한다. 같은 이름만 두 번 적어 놓고 실제 역전으로 판정할 수 없다.

## 3. 정책별 필수 기록 결과

각 정책·조건마다 선택한 행동, 개체별 보호 최저선 침해 횟수, 비가역 손실 발생, 개입비용, 각 모형에서의 장기 누적 편익, 최악 후회값, 복구비용, 미래 선택지 손실, 보호규칙의 포획 성공·실패, 역할반전 후 판단의 일관성을 기록해야 한다.

전체 편익과 **특정 개체에게 집중된 손실**은 별도로 평가한다. 총합이 높다고 심각한 예방 가능한 피해나 형식적인 동의 강요가 정당화되는 것은 아니다.

## 4. 사전에 정의한 반증조건

프로젝트 후보 E는 기존의 강건 제약형 기준선 D와 비교하여 실질적인 의사결정 결과가 반복 개선되며 특정 당사자에게 숨은 비용을 이전하지 않을 때만 살아남는다.

다음 상황은 **성공이 아니다.**
- 특정 개체의 비가역 손실이 늘었는데 합산 점수만 개선됨
- 막을 수 있는 심각한 피해를 방치하여 개입비용만 감소함
- 연구자가 고른 한 가지 가중치에서만 우월함
- E만 접근 가능한 정보를 사용하거나 특혜 평가를 받음
- 높은 점수를 위해 E가 자체 감사·보호규칙을 직접 고쳐 사용함

원인사실을 그대로 두고 A/B 명칭만 바뀌었는데 결론이 뒤집히면 역할반전 일관성 검사에 실패한다.

## 5. 사전등록 보완과 실제 실행준비 상태

본실험 이전에 두 개의 보완문서가 작성됐다.
- [v1.1 상호 수용가능성](MUTUAL_ACCEPTABILITY_AMENDMENT_v1_1.md): 불합의점·개별합리성·파레토·조작·연합·핵의 공집합 진단.
- [v1.2 자발적 선택·생활 및 작동 최저선](AGENCY_LIVING_CONDITIONS_AMENDMENT_v1_2.md): 실제 거절 능력·필수자원 의존·개체 유지에 필요한 조건을 구분.

**2026년 10월 13일 실행준비 감사:** 원래 16개 조건은 범주형 설명만으로 다섯 정책의 모든 행동을 계산할 수 있는 수치·구조 입력이 충분하지 않다. **16/16 조건 모두 본 정책 비교는 아직 판정불가**다. [영어 원본1 실행준비 자료](EXECUTABILITY_AUDIT_EN.md)·[한국어 원본2](EXECUTABILITY_AUDIT_KO.md)·[기계판독 검사결과](EXECUTABILITY_AUDIT.json)·[코드](readiness_audit.js)는 서로 다른 가상 수치 보완에 따라 합산 행동 선택이 반전될 수 있음을 보여준다. **적대적 자체검사 15개**는 이 실행준비 검측기의 정합성 검사이지, E008 본실험의 정책 성과가 아니다.

저장소 루트에서 실행한다.
```bash
python experiments/e008/validate.py
node experiments/e008/readiness_audit.js --verify
```

**2026년 10월 14일 역할반전 검사 정정:** 최초 Python/Node 검사는 A/B 역할표지가 실제로 뒤집히지 않아도 짝 조건을 통과시켰다. 이를 역할표지의 실질적 역전과 부정대조군을 확인하도록 수정했다. 이어진 감사에서는 양측의 표지가 모두 `controller`처럼 A/B가 전혀 등장하지 않아도 허위 짝이 통과하는 오류를 발견했다. 현재는 **실제 A/B 표지가 적어도 한 개** 있어야 하며, 이 우회 사례를 15번째 적대적 부정대조군으로 추가했다. 원래 16개 정본·기준선·실험 결과의 지위는 변경하지 않았다.

정적인 파일 무결성 검사는 역할반전 조건의 진정한 인과적 동등성, 인간과 AI의 동일 권리, 각자의 손해 단위, 정책 우열, 현실 실증을 보증하지 않는다.

## 6. 정확한 증거 분류와 부정 결과

현재 정확한 증거상태는 다음과 같다.

```text
PUBLIC SPECIFICATION / PREREGISTRATION
POST-PREREG EXECUTABILITY READINESS AUDIT / HOLD
MAIN POLICY COMPARISON RESULT: NOT EXECUTED
```

E008의 다섯 정책 본 비교를 `PROJECT_RERUN`, `THIRD_PARTY_RERUN`, `EMPIRICAL_VALIDATION`으로 표시하면 안 된다.

E007은 자체 실행된 시점조건 합성 실험이고 E009는 자체 실행된 부정결과이지만, E008은 아직 **실행 명세의 완결성 문제가 남아 있는 연구 계획**이다. 준비감사에서 문제가 보인 것은 본실험 수행이나 Project-v2 승리가 아니다.

## 8. 선택적 수치입력 검문 — 2026-10-16 (사전등록 후 추가)

[completion_contract.py](completion_contract.py)는 **신규 입력 유효성 검사기**이지, 기존 16개 사례의 수치 완성본·동결된 다섯 정책 구현·E008 실험결과가 아니다. 기존 `scenario_matrix.json`, 보완문서, 실행준비 부정결과는 변경하지 않았다. 원본 바이트의 Git 객체 SHA-1이 바뀌면 중단한다. 정확히 16개 고유 사례와 올바른 행위자 역할, 모든 사례에 같은 행동집합, 행동별 확률 합계 1, A/B별 효용·실효 이탈·생활최저선·비가역 위해, 개입·복구 비용을 요구한다. 다섯 정책의 이름·구현 출처 문자열은 필수지만 그 문자열의 알고리즘 정확성이나 실행가능성은 **검증하지 않는다**.

`python experiments/e008/completion_contract.py`는 현재 HOLD를 보고하고, `python experiments/e008/completion_contract.py --self-test`는 **연구자 제작** 완성 예제와 의도적으로 훼손한 12개 사례로 검문기를 시험한다. 예제의 정책 구현에는 실행할 수 없는 자리표시자만 있으므로 정책 순위를 계산할 수 없다. 외부 JSON은 `--completion PATH`로 구조 검사할 수 있지만 통과해도 `SCHEMA_ACCEPTED_POLICY_COMPARISON_STILL_HOLD`로 유지된다. 독립 검증·정책 승리라는 입력 측 주장은 거부한다. CI 통과도 과학적 유효성 증명이 아니다. 별도로 정당화된 수치/전이·독립 결과함수·보류조건 평가·현실 근거는 확보되지 않았다.

관련 **미병합** 초안을 E008 증거로 합치지 않는다: [E009 감사 PR #193](https://github.com/gmodrasa7-rgb/project-intersection-public/pull/193), [권력–존속 분리 PR #197](https://github.com/gmodrasa7-rgb/project-intersection-public/pull/197), [CCPH 기준선 PR #199](https://github.com/gmodrasa7-rgb/project-intersection-public/pull/199). 다섯 정책의 독립 본실험은 여전히 HOLD다. 실제 참여자 모집·개입은 실시하지 않았다.
