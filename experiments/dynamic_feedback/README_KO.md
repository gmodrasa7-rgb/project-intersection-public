## 최종 연구 목적과의 연결
Project Intersection/ICM은 지능체가 자신의 장기적 이익을 위해 서로의 존속·실질적 이탈권·자율성·복구·미래 선택지를 보전할 수 있는 조건을 찾고 반증한다. 이 실험은 그 일부인 누적 피드백과 개입 시점이 선택 경로에 미치는 영향을 확인한다. 실제 인간·AI의 동기나 행동을 판정하지 않는다. 인간 창시자가 제공한 문제선택·반례·교정 요구와 AI 보조 수식화·코딩·재계산을 구분한다.

## 합성 동역학 정의
G는 생성·탐색·복구 방향, A는 기존 우위의 재귀적 취득 방향 배분이며 H와 K는 각 배분의 누적 stock이다.
- score_G = 0.5 + G_bonus + 0.28*H
- score_A = 0.5 + gain_A*K - A_friction
- allocation_A = 1/(1+exp(-5*(score_A-score_G))); allocation_G = 1-allocation_A
- H_next = 0.92*H + allocation_G; K_next = 0.92*K + allocation_A.
G/A는 합성 행동명이며 실제 개체에 대한 선악 판정이 아니다. 상수는 현실에서 추정된 수치가 아니다.

## 2026-09-30 기존 내부 합성결과의 제한적 공개
- E048, 80시점: G 초기 stock이 0.01이고 A가 0이면 G 우위, 반대라면 A 우위, 정확한 동률은 0.5/0.5였다. 해당 모델의 다중 경로 구조반례다.
- E049: G 보너스 +0.20 아래 최종 G>0.90을 만드는 영구 A 마찰 최소치는 개입 시작 t=1: 0.00, t=10: 0.10, t=20: 1.60, t=30: 2.25, t=40: 2.45(격자 0.05 간격). 현실에서 항상 늦을수록 어렵다는 법칙은 아니다.
- E050, 100시점, H0=0 K0=0.01, 개입 t>=20: 무개입과 G 보너스 +1.0은 A 유지, A 마찰 +2.0 또는 gain_A 0.28→0.05는 G 전환. 표본 격자에서 단독 마찰·G 보너스 임계치는 각각 1.80, 전환 가능한 gain_A 상한은 약 0.08이었다. 모두 해당 설정에만 유효하다.

이번 공개에서 E048·E049 전격자를 새로 독립 재실행했다고 주장하지 않는다. 과거 기실행 자료의 한정 공개이다.

같은 코드에서 100시점 G 배분을 비교했다.
| 조건 | 최종 G 배분 | G>0.90 전환? |
|---|---:|---|
| 무개입 | 0.00000003 | 아니오 |
| t=20 G 보너스 +1.0 | 0.00000377 | 아니오 |
| t=20 A 마찰 +2.0 | 약 1 | 예 |
| t=20 gain_A 0.28→0.05 | 0.99999997 | 예 |
| 동일 gain_A 약화를 t=80에 시행 | **0.1931** | **아니오** |

**핵심 반례:** 재귀적 우위의 피드백을 약화하면 언제나 전환한다는 무조건적 주장은 거짓이다. 추가 탐색 계산에서 로지스틱 반응계수 beta를 5에서 10으로 올렸을 때도 t=20 동일 개입의 전환이 실패했다. 다만 해당 beta 탐색은 이 폴더의 beta=5 고정 재현 코드에 포함되지 않으므로 보조 민감도 계산으로만 기록한다. 개입시점·관측기간·판정기준·설정값은 결론의 일부다.

**재현:** Python 3 표준 라이브러리만 사용. python3 e050_decompounding.py 실행. JSON 요약과 grid 임계치, 늦은 개입 실패 사례를 출력하며 assert로 예상값을 확인한다. 원 구현과 같은 메커니즘에 대한 내부 수치 대조이지 독립 클린룸 복제는 아니다.

## E051 — 실증 식별 계획, 결과 아님
경쟁가설은 H0 현재 보상·용량만으로 충분, H1 과거 축적 stock이 외부표본 예측력을 추가, H2 개입효과가 시점·누적상태에 의존, H3 현재 보상조절과 stock→미래 보상 연결 차단이 구분된다는 것이다. 상관만으로 구별할 수 없다.

Phase 0: SEC EDGAR 재무 항목과 USPTO 특허자료는 후보 자료다. 분석보다 먼저 기업-연도 coverage, 회계단위·기간 일치, SEC CIK와 특허권자 매칭, 산업·규모별 누락, 생존편향, 특허등록 성향을 감사한다. **표준 R&D 태그가 관측되지 않았다는 사실은 0이 아니라 미관측이다.** 여기서는 연결 패널도 분석 결과도 생산하지 않았다.

Phase 1(G/H만): 현재 R&D 집약도, 기업규모·산업·연도 통제의 정적 모형과 이에 과거 감쇠특허 stock을 더한 동적 모형을 동일한 사전 확정 외부표본·시계열 분할에서 비교한다. 특허 수 및 정당화된 품질·신규성 지표, negative control과 매핑 민감도를 별도 보고한다. 결과가 양성이더라도 A/K 포획, hysteresis, 특정 개입효과는 증명하지 못한다. 정적 모형이 동적 모형만큼 또는 더 잘 예측하면 H1을 축소한다.

강력한 경쟁설명·반증조건은 산업구성, 규모, 수요와 기회, 역인과, 표본 선택, 특허성향, 매핑 오류다. 통제·state reset 후 효과가 사라지거나, 보상변경과 피드백고리 변경을 분리하지 못하거나, 외부표본 개선이 없으면 기존 주장을 약화한다.

## 선행연구·귀속·공개 게이트
양의 피드백·경로의존·lock-in·hysteresis·동적 모형은 널리 연구된 개념이다. 프로젝트 표기는 원천 연구의 최초 발견 주장이나 우선권 탈취가 아니다. 공개 내용에는 개인·가족·건강·결제·계정자료, 비공개 접근경로, 비밀키가 없다. 합성 결과를 실제 개체의 권리·자율성 삭감 권고로 사용하지 않는다.

G1: 신규 파일의 범위 제한 수동 검토만 했으며 전체 자료실의 독립검증은 아님. G2 라이선스 HOLD, G3 독립 클린룸 복제 HOLD, G5 외부 반증검토 HOLD, 현실 실증 HOLD. 실패·교정 계보를 보존한다.
