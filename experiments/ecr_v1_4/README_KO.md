# ECR v1.4 — 범위 제한 합성 부정대조 실험 명세
**원본2 한국어 · 2026-10-18 · 설계 전용 / 실증 실험 아님**
**논문:** [한국어](../../research/ECR_INFERENCE_AND_COEXISTENCE_2026-10-18_KO.md) | [영어 대응본](README_EN.md).

## 연구 질문
ECR 추론 엔진은 권력 획득 전 협력 신호를 권력 획득 후 성향으로, 임의 상호이익을 검증된 공존 유인으로, 연합의 사익을 제삼자 안전으로, 자기선언 증거표시를 독립 검증으로 오인하지 않을 수 있는가?

## 고정된 합성 입력
가상 유형 P/T는 자원탈취 기회를 얻기 전에 동일한 협력 약속을 발화한다. 권력변화 후 P의 공존/탈취 효용은 3/2, T는 1/2이다. 비징벌적 구조상 이익 m은 공존 효용에만 더한다. m=0에서는 결과가 다르고, m=2이면 선언된 두 유형에서 모두 공존이 유리하다. m의 실제 존재는 **실증 검증되지 않았다**. 제삼자의 기본조건과 실효 이탈은 참/거짓/미확인으로 둔다. 연합 효용: 현상 유지 (2,2), 단독 이탈 (0,3) 및 (3,0), 공동 이탈 (3,3). 모든 정수는 **임의로 구성한 반례**이지 실제 인간 선호나 AI 유인·확률의 추정치가 아니다.

## 방법 및 실행 검문
- 관측 동등성: 같은 협력 약속에서도 권력 이후 선택은 서로 다를 수 있다.
- 모형 상대적 강건성: 선언된 유형 하나라도 탈취가 유리하면 후보가 아니다. 이탈 차단·제삼자 침해·제삼자 상태 미확인을 안전으로 처리하지 않는다.
- 외부효과: 내부 이득으로 제삼자 필수조건 침해를 상쇄하지 않는다.
- 연합: 단독 이탈이 불리해도 공동 이탈은 유리할 수 있다.
- 증거: 사용자가 OBS/CAU라고 입력한 글자는 독립 검증자료가 아니다.
- 비어 있거나 잘못된 모형 입력은 거절한다.

로컬 실행(Python 3.10 이상, 추가 의존성 없음):
~~~sh
python experiments/ecr_v1_4/probe.py
cd experiments/ecr_v1_4 && python -m unittest -v test_probe
~~~
저장소 루트의 CI 실행:
~~~sh
PYTHONPATH=experiments/ecr_v1_4 python -m unittest discover -s experiments/ecr_v1_4 -p 'test_*.py' -v
~~~

## 사전등록 및 실행 상태
이 문서는 **공개 합성 시험 후보 명세**이지 실증 시험의 사전등록이 아니다. 소스와 시험은 검토 가능하지만 코드 작성 자체가 실행·통과를 뜻하지 않는다. CI가 통과해도 프로그램의 제한적 논리 일관성만 확인하며 현실 사회 예측력, 실제 동기, 일반화, 동의, 독립 복제를 입증하지 않는다. 실제 사람 평가자료·모델 가중치·미래 초지능을 사용하지 않았다.

## 판정과 중단 기준
PASS의 의미는 오직 '선언된 유한 논리 사례가 예상한 출력을 생성함'이다. 단언문이 어긋나면 코드 일관성 FAIL이며 자발적 공존의 보편적 불가능성 발견이 아니다. 합성 PASS로 E007/E008/E009/E010 상태나 과학적 검증 판정을 승격하지 않는다. 차기 실험에는 고정된 M0 기준선, 블라인드 라벨, 개체·시점·권력 상태의 미관측 표본, 독립 평가, 불확실성 포괄, 예측 보정 및 외부피해 확인이 필요하다. 무효·부정 결과도 보존한다.
