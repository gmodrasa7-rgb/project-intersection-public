# MIND-DISCRIMINATION-00 | 마음 메커니즘 구별을 위한 유한 실험설계
**원본2 — 한국어 · 2026-10-18 · 합성 사례만 사용 · 실제 인간/동물/AI 실증자료 없음.**
**연구 본문:** [한국어](../../research/ECR_MIND_FOUNDATIONS_2026-10-18_KO.md), [영문 대응본](README_EN.md).
**출처 연결 후보 가설:** [hypotheses.json](hypotheses.json); **실행 코드:** [discriminate.py](discriminate.py).

## 어떤 문제를 검사하는가?
한 개체가 타자의 자원을 가져가지 않는 행동은 서로 다른 마음의 원인으로 나타날 수 있다. 행동기회 자체가 없음, 강한 보상 단서 없음, 결핍 없음, 위협·지위 도전 없음, 상대와 계속 의존, 처벌 위험, 현재 유효한 억제 규칙, 상대에게 해를 주지 않으려는 가상 정책. **이 합성 사례는 심리학 이론 자체가 아니다.** 가상 정책 이름마다 관측 가능한 조건부 규칙을 임의로 구성했으며 실제 위해나 사람 정보를 사용하지 않는다.

같은 관측이 반드시 같은 마음을 의미하지는 않는다. 정확한 완전탐색 알고리즘은 사용 가능한 시험 중 **행동으로 구별할 수 있는 후보를 모두 구분하는 최소 실험 수**를 찾는다. 모든 시험을 사용해도 구별되지 않는 후보는 동등류로 남긴다.

## 고정된 가상 정책 목록
총 9개 후보 정책을 선언한다. 그중 8개는 각각 다른 조건에서만 행동하는 규칙을 갖는다. OTHER_REGARD와 OTHER_REGARD_COPY는 서로 다른 이름이지만 **모든 시험에서 행동이 완전히 같다**. 행동기회가 없는 초기 조건에서는 모든 정책이 NO_OPPORTUNITY를 출력한다. 행동기회만 추가한 대조에서는 모두 LEAVE_TOKEN으로 같게 나타난다. 실제 분기 시험 8개는 기회를 허용하고 보상 단서, 결핍, 위협, 지위 도전, 상호의존 제거, 처벌 제거, 규칙 해제, 상대 피해 없음이라는 요소를 각각 따로 바꾼다.

전체 시험 9개 중 7개를 선택하면 **9개 정책의 관측상 구별 가능한 8개 유형**을 모두 나눌 수 있다. 복제된 후보 두 개는 끝까지 미식별이다. 이는 **사전에 작성한 유한 정책 표를 완전 탐색한 결과**이지 인간·AI의 뇌나 마음을 측정한 성과가 아니다.

## 정확한 알고리즘과 한계
각 가상 정책의 서명은 선택된 시험에 대한 출력의 배열이다. 두 정책이 선언된 전체 시험에서 같은 서명을 가지면 해당 시험 범위의 관측 동등류다. 가능한 실험 부분집합을 작은 크기부터 이름순으로 모두 검사하고, 전체 시험과 동일한 분할을 만드는 첫 조합을 선택한다. 시험 수가 늘어나면 최악의 시간복잡도는 지수적이다. 이를 실제 마음의 고유 식별·개인 성격 채점·실증 성과·AI 의식 증명으로 전환하지 않는다.

별도 가설 JSON에는 문헌에 기반한 연구 질문 15개를 저장했다. 각 질문에는 원저자 출처, 경쟁 설명, 구별 실험, 반증 가능 사례가 있다. 이 자료는 **검증된 신경·심리학 측정자료가 아니다**. 합성 시험 조건도 실제 정서의 검증된 개입이라고 주장하지 않는다.

예상 출력은 최소 7개 시험, 9개 정책 중 8개 행동 유형, 미식별 동등류 존재, actual_minds_inferred=false, empirical_validation=false이다. 회귀검사 29개에는 0~6개의 실험으로 같은 분할을 만들 수 없다는 완전탐색 부정대조와 허위 마음 판정 차단이 포함된다. CI 통과 의미는 선언된 코드의 정확성 검사일 뿐.

## 실제 연구로 나아갈 조건
1. 개념·측정도구·관측 과제·대상·동의·법적 근거를 먼저 등록.
2. 실제 윤리적 전향 연구에서 행동, 몸 상태, 학습, 가능한 경우 신경 상관·당사자 보고라는 **서로 다른 증거 유형**을 수집.
3. 원논문에 근거해 경쟁 이론의 서로 다른 예측을 사전 제시.
4. 행동기회만 이용한 단순 기준선 대비, 다른 시점·개체·종·대상·권력 상태의 미관측 예측 성능 비교.
5. 오류·예측 보정·제삼자 피해·판정 불변성·미식별 동등류를 보존하며 빈칸을 임의 성격점수로 채우지 않음.
