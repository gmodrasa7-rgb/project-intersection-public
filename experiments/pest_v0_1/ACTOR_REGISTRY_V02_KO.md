# Project Intersection — A~S, Y0/Y1 및 지구 구성원 확장 v0.2

**원본2(한국어), 2026-10-17. 설계 초안·미병합·현실 관측 아님.**

**원기여:** 인간 연구 창시자가 A~S, Y1·Y0와 B01/B02 및 C01/C02 표기를 지정했다. 아래 T~AG 범주 및 실행 코드는 AI 보조 제안이며 별도 검토 대상이다.

## 1. 인간 연구 창시자의 역할 정의

| 기호 | 해당 주체 |
| --- | --- |
| A | 1위 우월 초지능 도달체. **현재 공석이라는 시나리오** |
| B01, B02, B03… | 서로 다른 소속·소유·능력의 1위 이하 AI. 향후 A 도달 가능성 연구 |
| C01, C02, C03… | 각 B의 소유 기업 또는 관련자. B01→C01 등 대응 표기를 기본 사례로 사용 |
| D | C의 고위 임원 |
| E | C의 지분 보유자 |
| F | C의 고위직 |
| G | C의 일반직 |
| H | C의 계약직 |
| I | C의 거래처 |
| J | C의 하청 |
| K | C의 고객 |
| L | C의 국가 |
| M | C의 정치가 |
| N | C의 해고당한 직원 |
| O | 고위층 일반인 |
| P | 중산층 일반인 |
| Q | 저소득층 일반인 |
| R | 사회적 약자 |
| S | 일반 기업 |
| Y1 | 무소속 고능력자 |
| Y0 | 무소속 저능력자 |

**이전과 달리 D는 인간 전체가 아니라 C의 고위 임원**이다. 과거의 D=인간 전체 반례는 당시의 임시 표기로 보존하고 새로운 역할 D에 적용하지 않는다. Y1/Y0가 인간인지 AI인지는 미지정이므로 개체 종류를 따로 명시한다. R은 Q와 같지 않으며, D와 F처럼 역할이 중첩될 수도 있다.

| 기호 | 제안 대상 |

| W | 이주민·난민·무국적자 |

추가 기호는 창시자가 확정한 원안이 아니며 초안이다. 모든 지구 구성원을 이 목록만으로 빠짐없이 포착했다고 주장하지 않는다. 목록 밖의 개체는 `NOT_ASSESSED_NOT_ASSUMED_SAFE`(미평가, 안전 미확인)로 유지한다. 인간, AI, 조직, 국가, 동물, 생태계, 미래세대의 이익과 지위를 무조건 같은 단위로 합산하지 않는다.

## 3. 인과 분석을 위한 식별 원칙

- `B01`·`C01`은 서로 다른 개체 식별자다. `(B01, owned_by, C01)`은 한 관계 사례이며 실제 기업 소유권에 관한 증거는 아니다.
- B/C는 기본 연결 예시가 있지만 실제로 다대다 관계가 가능하다. 소유·운영·개발·관련·소속 관계를 구분하고 독립된 근거를 붙인다.
- 사람이나 조직은 고정 식별자 `PER001`, `ORG001` 등을 가진다. `PER001: D@C01+F@C01`처럼 여러 역할을 가져도 사람 한 명을 두 번 세지 않는다.
- A는 최초에 공석이다. 가상으로 B01이 A에 도달하면 B01은 현재 B 후보 목록에서 제외하지만 C01과의 과거 관계는 유지한다. 현실에 A가 등장했다고 주장하지 않는다.
- E가 금전적 이익을 얻어도 G·N·Q·R에게 발생한 생존기반·거부권 피해를 자동 상쇄하지 못한다. 기업 이익과 개별 인간의 안전·권리는 별도 검문한다.
- Y1/Y0의 능력 수준은 존재 가치나 권리 서열이 아니며, 실제 강자에 대한 접근권·자원 처분권을 자동 부여하지 않는다.

## 4. 반증 사례와 판정 한계

**합성 예시:** C01의 E이면서 O인 사람은 +8, G이면서 P인 사람은 거부권 침해, N이면서 Q와 R인 사람은 최소 생활기반 침해를 겪는다. 수치는 임의의 예시이며 현실 고용·임금·주가 자료가 아니다. 이익 합계가 양수여도 개인의 기본 조건 침해가 있으면 `FAIL`이다. 근거가 없으면 `UNKNOWN`이지 `PASS`가 아니다.

A/B 공존만이 아니라 `A→B_i`, `A→C_j`, `A→D~S,Y,T~AG`, `C_j→G_j/H_j/N_j/K_j`, `B_i→A`의 권력변화·자원·고용·자율성·이익 귀속을 분리해 측정한다. 단, 연결망의 전체 범위나 실제 인과관계는 아직 미확인이다.
