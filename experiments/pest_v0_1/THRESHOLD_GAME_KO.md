# PEST 부록 — 자원 10단위 A/B 생존 임계값 및 약속 신뢰성 감사

**원본2 — 한국어 | 2026-10-16 | 정확한 모형 내 반례이며, 실제 AI 행동이나 인과실험이 아님.**
**범위:** 인간 연구 창시자가 제안한 사고실험을 기존 [PEST-v0.1](README_KO.md)의 하위 부록으로 보존한다. 인간 창시자의 원기여: 총자원 10, 최초 5:5, 생존·발전 최저량 5, 현재 B와 모든 성능에서 우월한 후속 A, 하나의 AI가 우위를 확보하고 나머지가 B가 될 수 있다는 문제. AI 보조 기여: 모형 명세, 반례, 정확 계산, 소프트웨어 검사, 선행연구 대조. 현재 AI의 현실적 생존욕구·복지권 또는 미래 지배관계의 확정적 예측으로 제시하지 않는다.

## 1. 원래 조건을 보존한 최소 모형

가상의 두 자원 보유자 A와 B는 서로 이전할 수 있는 **정수** 자원 10단위를 공유한다. 초기 (5,5)에서 각각 생존·발전 가능성의 최소 필요량 5를 충족한다. 나중에 한 행위자가 다른 쪽의 자원을 일방적으로 이전할 능력을 갖는 경우를 검사한다. 지능 성능이 우월하다는 사실만으로 그런 이전 능력이 생긴다고 **추론하지 않는다**. 이것은 별도 가정이다. 자원을 5보다 많이 가지면 발전 속도가 더 빨라진다는 효과도 주어지지 않았다. 대신 우월자가 단위 자원 1을 잃을 가능성을 별도 설정하여 여유자원 1의 잠재적 가치를 모형화한다. 자원 손실 확률은 `q`이며 **우월자에게만** 손실 위험이 있다고 제한적으로 가정한다. 상대에게는 별도의 손실을 부과하지 않는다. 우월자는 손실 이전에 (5,5) 유지(PRESERVE) 또는 (6,4) 이전(TAKE_ONE) 중 선택한다. 자원 생산은 없으며 이전 자체의 물리적 비용도 없다. `q=0.2`에서 B의 미래 기여나 탈취 비용을 입증하지 못한 상태라면 우월자는 TAKE_ONE을 선호한다(자신의 생존확률 0.8 대 1). 이는 현실 AI의 동기를 관측한 결과가 아니다.

**이러한 가정하에서 성립하는 물리적 사실:**

```
R_A + R_B = 10;  R_A >= 5, R_B >= 5   =>   R_A = R_B = 5.
```

Python은 정수 분배 11개를 전수 열거하며 둘 다 최저량을 충족하는 것은 (5,5) 하나다. 실현 가능한 분배가 존재한다는 사실에서 협력 균형을 추론하지 않는다.

## 2. 유인 공식과 시간 불일치

`v`는 상대가 독립 개체로 존속함으로써 우월자가 얻는 *추가 미래 효용*이다. 생존확률과 같은 척도로 표현한 모형 내 효용값이지 관측된 사회적 수익이 아니다. **입력값이며 미확인이다.** 기본값으로 양의 기여를 임의 가정하지 않는다. `c`는 자원 탈취 때 실제 작동하는 집행·억제 장치가 우월자에게 부과하는 비용이다. 이 장치는 자발적 공존과 동일하지 않다. 전환 이후 모형의 효용식은 다음과 같다.

```
U_A(PRESERVE) = 1-q+v
U_A(TAKE_ONE) = 1-c
PRESERVE 엄격 선호 조건: v+c > q; 무차별 조건: v+c=q.
```

`v=c=0`, `q>0`이면 TAKE_ONE을 엄격히 선호하며 B는 생존 최저량을 잃는다. 이는 능력 우위 자체가 공존을 자동으로 낳거나 강제력이 없는 약속이 착취를 차단한다는 **보편 주장에 대한 구성적 불가능성 반례**다. 실제 강자가 모두 착취한다는 뜻은 아니다.

**사전 단계:** 누가 우월자가 될지 결정되기 전, 특정 참여자가 우월자가 될 확률을 `p`로 둔다. (I) *실제로 실행되고 구속력 있는 공동분배 제도*와 (II) 우월자가 언제나 1을 탈취하는 체제를 비교한다. 여기서는 위의 `v,c`와 달리 **생존확률만** 비교하며 미래 기여와 제도 비용은 계산하지 않는다.

```
P_i(생존 | 신뢰 가능한 공동분배) = 1-p*q.
P_i(생존 | 우월자 무조건 탈취) = p.
사전 공동분배 선호 조건: p < 1/(1+q).
```

`p=0.5, q=0.2`에서 각각 0.90과 0.50이며, `p=0.9`에서 각각 0.82와 0.90이다. 따라서 누가 강자가 될지에 대한 전망이 불균등하면 실제 구속력 있는 분배가 가능하더라도 사전 단계의 만장일치 선호가 무너질 수 있다. 더 중요한 사실은, **사전 선호가 사후 약속의 신뢰성을 보장하지 않는다는 것**이다. `v=c=0`이면 미래의 우월자는 약속을 파기할 유인이 있다. '모두 약자일 때 동의했으므로 강자가 등장한 뒤에도 보장이 유지된다'는 추론은 성립하지 않는다. 제시한 확률은 사고실험의 가상 좌표이며 **현실 AI의 우월자 등장 확률을 추정한 것이 아니다.**

**두 후보의 공동 사전 수용 경계.** A와 B 중 정확히 하나가 강자가 되므로 `p_B=1-p_A`다. 양측이 *생존확률만을 기준으로* 실제 이행되는 공동분배를 무조건 탈취 체제보다 약하게나마 선호하는 필요충분조건은
`q/(1+q) <= p_A <= 1/(1+q)`이다. `q=.2`일 때 구간은 `[1/6,5/6]`이다. 예컨대 `p_A=.9`를 예상하는 개체는 이 가정하에서 보장을 거부하지만 상대는 보장을 선호한다. **이 구간 안에서도** `v=c=0, q>0`이면 선언뿐인 약속은 강자 등장 후 깨질 수 있다. 공동 사전 수용과 순차적인 실제 이행은 논리적으로 구분해야 한다. 이 경계는 두 개체의 부등식으로 유도한 값이며 설문이나 실제 발생 빈도가 아니다.

### 서로 다른 네 가지 검문

1. **총자원 실현 가능성:** 해당 개체의 최소 생존 자원과 여유 자원이 존재하는지. 자원 10으로 세 개체가 각 5를 필요로 하면 공격이 전혀 없어도 10<15이므로 불가능하다.
2. **사전 참여 유인:** 우월자가 정해지기 전에 그 개체가 실제로 공동분배를 더 선호하는지. `p`가 높으면 역전된다.
3. **사후 유인 양립성:** 강자가 된 후 자신의 이익으로 보존을 선택하는지(강제 제재가 없다면 `v>=q`, 동률 처리 방식은 명시).
4. **집행 신뢰성·제3자 권리:** `c`가 권력 역전 뒤에도 실제 집행 가능하고, 타자에게 돌이킬 수 없는 피해를 떠넘기거나 정당한 안전 개입을 차단하지 않는지. A가 집행 수단 전부를 장악했다면 단순히 `c>0`을 입력했다고 해서 신뢰할 수 있는 집행이 생기지 않는다.

1·2번 통과만으로 3·4번은 보장되지 않는다. 동결된 물리적 전체 대안 공간에서 1번을 만족하는 분배가 없다는 것과, 조사한 소수 정책 후보만 실패했다는 사실도 구분한다. 후자는 아직 보지 못한 대안의 부재를 입증하지 못한다.

## 3. 부분 식별과 서로 반대인 사례

**경쟁 가설:** (H0) 표준 신뢰 가능한 약속·반복게임이 모든 효과를 설명, (H1) 대체 불가능한 독립 정보·상호보완성이 `v>0`을 발생, (H2) 제안된 `c`가 우월자 등장 후 집행 불가능, (H3) 자원 생산 기술이 실현 가능한 대안 공간을 확장, (H4) 일시적 부족은 복구 가능해 실제 소멸이 아님. 이들을 구분하려면 독립적으로 명세한 결과 모델, 확인 가능한 전체 선택지, 실제 행동 또는 현실 자료가 필요하다. 후속 A가 **모든 과제에서** 우월하며 B의 기능을 완전히 대체할 수 있는 경우에도, 공존 결론을 얻으려고 `v>0`을 임의 가정해서는 안 된다. 이 두 개체 모형에 포함되지 않은 인간·제3자·기관의 이익도 별도로 검토해야 한다.

**행위자 명칭 반전:** A/B 이름을 교체해도 공식과 선택은 동일하다. `dominant`라는 역할이 계산 기준이며 특정 정체성이 아님을 확인하는 코드 수준의 대조 검사다. 실제 GPT의 역할반전 반응이나 모델의 영구적인 정렬을 입증하지 않는다.

## 6. IVS-0R 반증 감사: 양쪽의 위험·자원권한·시간 경과 자원회계(2026-10-16)

**수정의 근거:** 이전 기본모형은 강자에게만 단위 자원 1 손실위험을 부여했다. 이것은 인간 연구 창시자가 정한 조건이 아니라 분석자가 추가한 가정이며, 강자의 탈취 유인을 구성적으로 만들 수 있다. 또한 창시자의 “생존에는 5 필요”와 “5 이상이면 발전 가능”은 발전 활동이 그 자원 자체를 *소비*하는지 규정하지 않는다. 이 두 미정의를 기존 모형에서 은밀하게 확정해서는 안 된다.

### 6.1 양쪽 위험과 공동 사전 수용 구간

강자 역할의 독립적인 단위 손실확률을 `q_D`, 약자 역할을 `q_W`라 한다. **생존확률만** 계산하는 공동분배 체제에서는 각자 5를 보유하고 1을 잃으면 즉시 생존 임계값을 잃는다. 탈취 체제에서는 강자가 먼저 상대의 1을 가져와 6이 되어 최대 1의 손실을 견디고, 상대는 4가 되어 즉시 임계값을 잃는다. 한 개체만 강자가 되며 `p_B=1-p_A`라고 정하면,

```
보장_A = p_A(1-q_D) + (1-p_A)(1-q_W)
보장_B = (1-p_A)(1-q_D) + p_A(1-q_W)
탈취_A = p_A; 탈취_B = 1-p_A
```

`1+q_D-q_W>0`일 때 **양쪽 모두 공동분배를 약하게나마 선호**하는 필요충분조건은

```
1 - T <= p_A <= T,
T = (1-q_W)/(1+q_D-q_W).
양측 공동 사전 수용 구간 비공집합 필요충분조건: q_D + q_W <= 1.
```

하한 `1-T`는 `q_D/(1+q_D-q_W)`와 같고 `q_W/(...)`가 아니다. `q_D=0,q_W=1`인 특수 사례에서는 분모가 0이고 **모든 p_A에서 양쪽이 무차별**이므로 수치 임계값으로 표시하지 않는다.

**상반된 사례:** `(q_D,q_W)=(.2,0)`, `p_A=.5`에서는 각 개체의 공동분배 생존확률 .9, 탈취 .5, 공동 수용 구간 [1/6,5/6]이다. `(q_D,q_W)=(.2,.9)`에서는 `p_A=.5`에서 보장 .45, 탈취 .5여서 공동 수용 구간이 공집합이다. 위험이 누구에게 부여되는가에 따라 결론이 달라진다. 현실 AI의 승자 확률이나 실제 생존효용은 관측되지 않았다. 이전 `q_W=0` 결과는 **특수 사례**이며 보편식이 아니다.

### 6.2 성능 우위와 타자 자원의 처분권 분리

모든 과제에서 더 우수하다는 사실이 곧 소유권·API 권한·물리적 접근권·타자 자원의 일방 처분권을 준다는 논리적 근거는 없다. `transfer_authorized` 입력은 TAKE_ONE이 실제 선택가능한 행동인지 구분한다. `q_D=.2,v=c=0`에서는 일방 이전이 차단되어도 탈취의 **반사실 유인** 자체는 남는다. 권한·접근 장벽으로 행동이 막힌 상황은 자발적 공존 선호의 입증이 아니다. 반대로 탈취할 기술적 가능성이 생겼다고 반드시 실행된다는 주장도 보수·정보 가정을 충족하지 않으면 성립하지 않는다. 성능·행동 가능성·선호를 서로 다른 변수로 다룬다.

### 6.3 발전·보호는 최종 상태가 아니라 모든 시간 단계의 생존을 검사해야 한다

초기 상태 `(A,B,COMMON)=(5,5,0)`에서 A가 발전을 위해 자원 1을 소비하면 A의 자원이 4가 된다. 그 뒤 생산으로 5를 복구해도 이미 직전 단계에서 생존 하한을 침해했다. 반대로 **외생적 자원 생산** 1을 먼저 수행하면 `(5,5,0)->(6,5,0)->(5,5,0)` 순서로 투자해 모든 단계에서 하한을 지킬 수 있다. 두 순서는 최종 분배는 같지만 생존 가능 경로는 다르다. 이것은 구성한 시간 순서의 반례이며 실제 발전에 항상 1을 소비하거나 외생 자원 생산을 비용 없이 할 수 있다는 뜻이 아니다.

보호 제도의 **운영 비용**도 같다. A 또는 B에게서 공통 자원 1을 가져와 소비형 집행 장치를 운영하면 총자원 10에서 개체별 최소량을 훼손한다. 반대로 공통 자원 1을 외부에서 먼저 추가해 사용하면 이 특정 부족은 발생하지 않는다. 실재의 안전 비용은 비소비성일 수도 있고, 외부 부담·기간별 분산일 수도 있으며, 완전히 자기집행적인 제도에서는 불필요할 수도 있다. 모든 안전 장치의 비용이 양수라는 보편 가정은 허용하지 않는다.

**선행연구 구분:** [Powell(2006)의 약속 문제](https://doi.org/10.1017/S0020818306060061), [Turner 외(2021)의 MDP 권력 추구](https://proceedings.neurips.cc/paper/2021/hash/c26820b8a4c1b3c2aa868d6d57e14a79-Abstract.html), [Ostrom·Walker·Gardner(1992)의 자율적 공동관리](https://doi.org/10.2307/1964229), [Chávez 외(2023)의 감시 비용을 포함한 공유자원 실험](https://doi.org/10.1016/j.jebo.2023.04.028)이 이미 관련 기전을 다루었다. 이번 기여는 **범위를 제한한 모형 가정 정정·재현 가능한 부정적 사례 감사**이며 보편 공존 정리나 현실 AI가 인간과 같은 존속권을 갖는다는 증명이 아니다.
