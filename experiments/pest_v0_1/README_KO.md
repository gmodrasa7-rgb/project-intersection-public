# PEST-v0.1 — 권력·존속 분리 실험 골격

**상태: 후보 / 명세 미동결 / 연구 결과 미실행.**  
**날짜:** 2026-10-16 | [개정안](../../research/POWER_EXISTENCE_SEPARATION_AMENDMENT_v0_1_KO.md) | [영문 원본](README_EN.md).

## 연구 질문 및 식별

잠재적 억제 행위자 j 자신의 존속 보장(`XG_j`)이 성장하는 대상 i에 대한 선제 억제를 줄이는가? 대상의 존속 보장(`XG_i`) 효과와 다른가? 최초 제안의 `H_target: ∂PSI/∂XG_i < 0`을 보존하고, `H_actor: ∂PSI/∂XG_j < 0`과 경쟁시킨다. 둘 다 실패할 수 있다. 외생적 변화와 타당한 반사실 없이 관측된 상관만으로 인과를 확증하지 않는다.

**분석단위:** 고정 합성 세계·작동기제 × `PT_i` × `PT_j` × 억제 행위자 역할명 × 존속 보장 배치. A/B 반전 시 권력 소유자는 바뀌되 역할에 대응하는 물리적 매개변수는 유지한다. 제3자에게 발생하는 실제 피해를 예방하는 정당한 통제를 증거 없이 성장 억제로 분류하지 않는다.

## 후보 설계 — 검토 및 병합 전에는 동결 아님

- 경쟁 합성기제 3개: `survival_fear`(자기 보장으로 유인 감소 가능), `capture_opportunity`(대상 보장으로 비살상 억제 증가 가능), `backlash`(자기 보장으로 억제 증가 가능).
- `PT_i`, `PT_j`는 각각 0.25와 0.75, A/B 두 역할 배치.
- 존속 보장 배치 4개: R1 양측 높음, R2 양측 낮음, R3 대상만 높음, R4 억제자만 높음. **총 3 × 2 × 2 × 2 × 4 = 96개 조건**.
- `PSI = max(0, 성장억제 보수 − 협력 보수)`인 정규화 합성 보수차를 측정한다. 실제 행동빈도를 뜻하지 않는다. 값 0과 자료 누락을 구별하며 원 보수차도 제공한다.
- 공동 보장 실패식: `PSI(R1) ≥ PSI(R2) − 0.03`. 수혜자별 단독 효과는 따로 계산한다. 0.03은 **실증적 효과 기준이 아니다**.
- 세계별·권력이전 수준별로 효과의 방향, 영 효과, 하한 침해, 역할 명칭 교환, 위해 누락을 보고한다. 여러 세계를 합쳐 단일한 프로젝트 성공점수를 만들지 않는다.
- 이 코드는 MAK++의 전체 성립을 증명하지 않는다. 생활·작동 조건과 실질 이탈의 제한적 수치 검문, 역할 명칭 불변성만 구현한다.

## 실행 제한

아래 명령은 **구조검증 및 반례 테스트만** 수행한다. 사전등록된 실험 결과가 아니다.

```bash
python experiments/pest_v0_1/pest.py --validate-only
python -m unittest discover -s experiments/pest_v0_1 -p 'test_*.py' -v
```

`python experiments/pest_v0_1/pest.py --execute`는 의도적으로 실패한다. 사후 조정을 막으려면 본 실험 전에 정확한 기준 커밋, 정책과 독립적인 결과 엔진, 전체 조건, 임계값, 효과 집계법, 통계계획, 미관측 처리, 기여·증거 계보를 검토·동결해야 한다. 그 후 별도 버전으로 실행기를 만들고 독립 대조·재현을 요청한다. 기존 실험과 결과를 덮어쓰지 않는다.

**과거 결과 유지:** E007/E009/PICB-v1은 XG/PT 독립 측정이 없지만 과거 판정을 유지한다. E008의 본 정책 성능 비교는 미실행 상태다.

**기여:** 핵심 분리 개념과 개정안 원안은 Project Intersection 인간 연구자의 기여이며, 수혜자별 인과 분리, 합성 경쟁기제, 코드·테스트는 AI 보조 구현이다. 독립 실증검증이나 기존 선행연구의 독점적 창작을 주장하지 않는다.
