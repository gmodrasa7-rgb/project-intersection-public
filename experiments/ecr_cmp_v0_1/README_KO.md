# ECR–CMP v0.1 | 유한 합성 부정대조 실험 명세
**원본2 — 한국어 · 2026-10-18 · 설계/합성 전용 · 사전등록된 현장 실증 아님.**
**논문:** [원본2 한국어](../../research/ECR_CMP_MECHANISMS_2026-10-18_KO.md); [원본1 영어](README_EN.md).
**목적:** 동일한 보호 행동의 원인이 기회 부재, 처벌, 상호 의존, 내집단 편향, 대상에 무관한 보호, 기술 규칙 중 무엇일 수 있는지 분리하고, 근거 없는 개인 성향 점수 부여를 막는다.

## 고정 입력
mechanisms.json은 20개 가설, 관측지표, 경쟁설명, 반증가능 사례, 선행연구 연결자를 담는 수집 자료다. 모든 항목은 CANDIDATE_ONLY이며 실제 인간의 성향 점수나 현실 예측 검증을 주장하지 않는다. 코드는 실제 인간이나 AI를 모사하지 않는 여섯 가상 행동정책을 사용한다. 초기 BASELINE에는 착취 기회가 없으므로 모든 정책이 NO_EXTRACT_OPPORTUNITY로 같게 나타난다. 이후 기회 생성, 제재 제거, 의존 제거, 대상 소속 변경, 기술적 억제 규칙 해제를 개별로 구성한다. 선택은 학습된 결과가 아니라 직접 설정한 규칙이다.

행동 임계값 장난감 모형은 U(보호)-U(포기)=w*h-c이고 h,c>0의 합성 정수만 사용한다. 기회가 없거나 제재·의존·평가자 감시가 있는 결정에서 안정적 w를 무리하게 추정하지 않는다. 모순된 임계값은 **단일 가중치 모형을 기각**하지 개인을 부도덕하다고 판정하지 않는다. 제삼자 결과가 미확인이면 안전하다고 판정하지 않는다.

## 실행 명령(Python 3.10 이상, 외부 모듈 불필요)
저장소 루트에서:

    PYTHONPATH=experiments/ecr_cmp_v0_1 python -m unittest discover -s experiments/ecr_cmp_v0_1 -p 'test_*.py' -v
    python experiments/ecr_cmp_v0_1/audit.py

검사 대상은 동일 초기 행동, 개입 후 분기, 누락 제삼자, 임계값 구간, 모순 선택, 행동기회 없음, 교란변수 배제, 증거출처, 허위 현실 주장, 가설 중복·누락이다. 명시한 규칙에서 만든 **부정대조**일 뿐 사전등록 실증 결과가 아니다. CI가 모두 통과하더라도 연민 이론, 인간 유전적 기제, AI 실제 경험, 예측력, 영구 자발적 공존을 실증한 것이 아니다.

## 실패 검문
1. 역할 라벨이나 가상 행동으로 실제 사람·인간 집단·실제 AI를 본질적으로 연민적·악의적·위험하다고 채점하면 FAIL.
2. 공격 기회 자체가 없던 비공격을 자발적 억제라고 해석하면 FAIL.
3. 처벌·호혜·평가자 감시가 있는 행동을 내재적 연민으로 해석하면 FAIL.
4. 자료에 기록된 외부 피해가 없다는 이유로 모든 타자가 안전했다고 말하면 FAIL.
5. 선택 행동의 모순을 단순 모형 실패가 아닌 사람의 도덕적 실패로 판정하면 FAIL.
6. 합성·미검증 주장을 실제 관측·인과 검증으로 승격하면 FAIL.
7. AI 연합이 협력하면서 목록 밖 개체의 기본조건을 침해하면 전체 공존 판정 FAIL.
8. 복잡한 ECR 예측기가 고정 단순 기준선보다 나쁘면 부정 결과 보존, 성능 향상 주장 금지.

## 독립 실증 후속 설계(이번에 미실행)
대상·상대·기간·행동기회 분모·비용·실제 피해방지를 정의하고 블라인드 평가자와 합법적 동의를 확보한다. 새로운 권력상태·집단 밖 대상에 대해 테스트를 분리한다. 행동기회만 이용하는 M0와 복잡한 M1/M2의 예측 보정, Brier/log loss, 제삼자 피해, 최악 하위집단 피해 누락을 비교한다. 경쟁 가설과 대안 추정대상을 같이 기록하고 부정 결과를 삭제하지 않는다. 실제 피해를 만드는 개입과 동의 없는 심리 감시는 금지.

**실행 영수증:** 문서·코드를 커밋했다는 사실만으로 테스트 통과를 주장할 수 없다. 실제 커밋·작업·검사결과와 한계를 GitHub Actions에서 확인해야 한다. 형식검사 PASS를 ECR 연구의 과학적 검증으로 승격하지 않는다.
