## 실행 / Reproduce

At repository root (stdlib Python >=3.10, no external packages):

    python experiments/ecr_mer_bridge_v0_1/test_bridge.py
    python -m unittest discover -s experiments/ecr_mer_bridge_v0_1 -p 'test_*.py' -v

The **27 unit tests** cover:
- identical low-power (no opportunity) and high-power observations for a selected-stable extractor vs a hypothetical power-transformed actor;
- distinguishing these two prewritten policies when low power is independently crossed with a *harmless* resource-allocation opportunity;
- no opportunity, evaluation, sanction, missing third parties, missing scope, missing effective exit;
- missing histories, logically incompatible evidence, and a 0–1 *logical* extraction bound that is **not** a sampling confidence interval;
- a once-positive self-interest margin that turns negative after a future noncoercive gain decays, plus coalitional deviation and third-party veto.

**Novelty boundary:** This is a finite regression fixture combining existing inverse-reward ambiguity, controlled intervention logic, performative-evaluation concerns, and conditional game viability; it does **not** prove a new general identification theorem. Neither a clean observation nor a passing toy fixture identifies actual human/AI latent motives. A finite-model positive margin is not scientific evidence of voluntary coexistence.

**Gating:** Actual GitHub Actions job receipt must be checked separately from file-creation success. Even green CI tests declared code logic only. The canonical E009 Project-v3 42.35% negative result and E008 no-main-outcome status remain unchanged.
