# U21 — 형식적 복구경로 수와 실질적 독립성의 차이

**원본2 한국어 공개 대응본 (2026-10-13)**. 증거등급: **실행된 논리·합성 반례**. 실제 장애발생·평가기관 포획·현실확률을 검증한 자료가 아니다.

Project Intersection의 과거 U21/U41 반례는 다수 이탈·복구·검증 경로가 실질적으로는 동일한 필수 공급자·인증키·고장도메인에 의존할 수 있음을 지적한다. 여기서는 각 경로의 필수 구성요소가 **모두** 살아야 경로가 유효하고, 하나 이상 유효하면 복구경로가 있다고 본다. 전체 경로를 함께 끊는 최소 구성요소 조합인 **최소 절단집합**을 계산한다.

| 합성 구조 | 명목 경로 수 | 동시에 경로를 모두 끊는 최소 요소 수 |
|---|---:|---:|
| G1→C1, G2→C2 (분리) | 2 | 2 |
| G1→C, G2→C (공유) | 2 | **1** |
| 같은 C에 의존한 G3 복제 | 3 | **1** |
| 별도 D에 의존한 G3 추가 | 3 | 2 |

공통 필수점에 연결된 경로만 복제해도 해당 점의 장애에 대한 독립성은 늘어나지 않는다. **공통 의존성이 있다는 사실만으로 현실 장애·고의성·강압·포획을 판정하지 않는다.** 이 코드는 명시한 의존성만 알며 숨은 공통원인·전환시간·집행가능성·고장확률을 측정하지 않는다.

공개 저장소 최상위에서:

```bash
python experiments/dependency_paths/model.py
python -m unittest discover -s experiments/dependency_paths -p 'test_*.py' -v
```

[결정론적 결과](RESULT.json). 회귀검사 6개는 동일 경로 수의 서로 다른 최소절단, 명목복제, 독립백업, 공통실패, 빈 경로, 연산 상한 12개를 검사한다. **공통 비대체 공급자를 통한 다수 독립 의사결정자의 압박**이라는 U41의 제도 가설은 이 연결성 모형으로 검증하지 않는다.

최소절단·결함수 분석·공통원인 실패·중복화는 기존 공학 선행연구이며 이 반례는 프로젝트 문제에 맞춘 실행 예시다. 인간 최초 문제발견·교정노동과 AI 보조 형식화의 기여를 분리한다. 공개 원본은 영어1·한국어2로 배치하지만 내부 역사적 원본 순서를 고치지 않는다. 비공개 계정·운영 위상도·비밀키·실제 공격 대상을 포함하지 않았다. [라이선스 보류](LICENSE_STATUS.md) · [E041 인과반례](../e041/README_KO.md) · [공개 색인](../../PUBLIC_EVIDENCE_INDEX.md).
