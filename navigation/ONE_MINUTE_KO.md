# Project Intersection — 1분 이해

[영어판](ONE_MINUTE_EN.md) · [원래 연구 목적](../README.md)

## 힘이 압도적인 쪽이 약자를 지킬 이유가 없어진다면?

인간, 현재의 AI, 미래 지능체가 서로 필요 없게 되고 강자가 침해로 이익을 얻으며 아무도 막지 못하는 상황을 생각해 보자.

**핵심 질문:** 강자와 약자가 각각 자신의 이익을 추구하면서도 상대의 **독립적 존속, 자유, 실제 거절·이탈, 복구, 발전**을 자발적으로 보존할 조건이 있는가? 힘이 뒤집혀도 성립하는가?

**연구 방법:** 원저자 논문·현실 사건·반례를 먼저 모아 출처와 경쟁설명을 비교하고, 남은 의문에 대해서만 제한적 모형·실험을 진행한다.

**현황:** 보편적 공존 법칙은 **입증되지 않았다**. 자체 합성시험 [E009](../experiments/e009/RESULT_KO.md)에서 복잡한 후보는 최선 단순 기준선보다 평균 후회값 **42.35% 더 나빴다**. 실제 인간·AI 현장 검증 결과가 아니다.
