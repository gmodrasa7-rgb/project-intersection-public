## 근거 단계는 하나의 점수로 합산 불가

- **선행 원저자 연구:** 원저자에게 귀속. 표본·방법·상반 근거 구분.
- **프로젝트 합성시험:** 명시한 모형의 계산 결과. 실제 마음·인과·장기 공존 실증 아님.
- **사전등록·미실행:** 실험 설계가 실제 수행 결과를 대신하지 않음.
- **초안/HOLD:** 미병합 PR은 공식 main 결과에 자동 포함 불가.
- **UNKNOWN:** 영(0)이나 사실상 부정·긍정 판정으로 치환 금지.

## 자료실의 실제 위치

| 저장 경로 | 의미 |
| --- | --- |
| `research/`, `prior-art/` | 연구 가설·경쟁설명·선행 원저자 |
| `experiments/`, `evidence/` | 실험 명세·코드·조건부 결과 |
| `knowledge/` | 서지 정체성·출처·증거 계보 |
| `navigation/` | 시작 안내·연구 버전·분류별 목차 |
| `operations/`, `funding/` | 연구 유지·지원정보, 과학적 인증 아님 |
| `tools/`, `tests/`, `.github/` | 자동점검·CI, 외부 독립검증 대체 불가 |

**접근성 한계:** 파일·링크 유무와 목차 구조는 자동점검 가능. 실제 모바일 읽기·키보드·스크린리더 이용성, 언어별 의미 동등성, 연구 내용의 사실성은 독립적 사람과 근거 확인 필요. 원래 파일 위치는 역사적 출처 연결을 위해 유지. [불편·오류 신고](../.github/ACCESSIBILITY.md).
