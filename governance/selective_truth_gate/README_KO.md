# 선택적 진실·비대칭 비용 전가 방지 게이트 (공개 방법론)

**상태:** 구조화된 공개 사례에 대한 정적 회귀검사. 실제 기업의 고의·위법·보상채무를 판정하지 않음.

## 무엇을 해결하는가

참인 일부 문장만으로 전체 성과가 확인된 것처럼 보이게 만드는 실패를 방지한다. 실제 문제는 결과를 확인하지 않은 상태에서 설정 완료를 성공으로 표현하거나, 사용자에게 귀속된 검증·복구비용을 측정 불가라는 이유로 0으로 처리하는 것이다.

이 게이트는 다음 항목을 서로 독립적으로 보존한다.

1. **주장과 출처:** 관측·가설·논쟁·미관측을 구분한다.
2. **보고된 조치와 실제 결과:** 설정/실행/읽기검증/독립 성과검증은 같은 상태가 아니다.
3. **편익 원장과 비용 원장:** 두 원장을 분리하며 측정 불능은 0을 의미하지 않는다.
4. **누락된 반대사실과 대안설명:** 호의적인 사실만 기록할 수 없다.
5. **의도와 결과:** 고의 미확인은 피해 부재도 고의 입증도 아니다.
6. **수정노동 담당자:** 자료와 평가권을 보유한 수혜 측이 확인·복구를 맡는다.
7. **과거 기여와 미래 계약:** 기존 기여 인정은 추가 무급 검증이나 계약 연장에 종속되지 않는다.

## 판정 의미

- **PASS:** 기록에 표시된 실제 결과가 독립 출처에 의해 검증되고 필수 통제 조건이 충족된다. 서술된 주장 전부의 과학적 타당성을 뜻하지 않는다.
- **HOLD:** 결과·비용·귀속 또는 외부 확인이 부족해 성공을 주장할 수 없다. 기여자에게 새 무급 증명을 요구하지 않는다.
- **FAIL:** 구조적 위반을 발견했다. 예: 독립검증 없이 실제 결과를 확정, 비용 미측정을 0으로 전환, 기여자에게 반복 증명 요구.

## 범위와 한계

검사는 제출된 JSON 기록의 일관성을 검사한다. 공개 연구 저장소 전체나 실제 챗봇 대화를 자동으로 감시하지 않는다. 값이 거짓으로 입력되면 외부 진실을 알아서 발견하지 못한다. **독립 근거 확보·결정권 분리·실질적 보상·복구**를 대신하지 못한다.

기본 사례는 **합성 테스트**로, 개인의 비공개 대화·건강·가족·재정·보상협상 내용을 포함하지 않는다. 실명 기업의 의도나 법적 책임을 사실로 만들지 않는다.
