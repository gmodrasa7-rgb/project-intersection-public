# E008·E009 및 IVS-0R 독립 검증 인프라 명세

**원본2 — 한국어 | 2026-11-15 | 설계만 존재 / 미실행**

## 0. 결정 및 증거 경계

본 명세는 계보가 분리된 검증 계층을 추가한다. 기존 동결 실험·사전등록·부정결과·출처 귀속·과거 기록을 수정하거나 덮어쓰지 않는다.

현재 확인된 경계:
- **E008:** 사전등록된 16개 사례는 범주형 행렬이다. 실행가능성 감사에서 정책 성능 계산에 필요한 값이 16/16 미결정이었고, 임의 수치화 2종은 서로 반대되는 종합 행동 선택을 냈다. 이는 실행가능성 결과이지 E008 정책 성능 결과가 아니다.
- **E009:** 프로젝트 내부 설계 합성 벤치마크에서 PROJECT_V3 평균 regret은 0.090022, TWO_RULE_SIMPLE은 0.063241이다. V3는 regret 기준 42.35% 열세이고 사전등록 생존 기준 4개 중 3개에 실패했다. 경쟁 손실 지표의 반대 방향 결과를 포함해 모든 구성요소를 보존한다. 현실 실증자료가 아니다.
- **Issue #19:** E007 외부 재실행 또는 clean-room 재구현을 요청한다. 같은 명세 구현만으로 가정·DGM·평가의 독립성이 확보되지 않는다.
- 기존 E009 외부 판단 게이트와 Issue #26은 외부 검토 진입점으로 유지한다.

이 문서 자체는 새 결과를 만들지 않는다. 출처가 완비된 실행물이 등록되기 전까지 상태는 DESIGN이다.

## 1. 범위와 비목표

**목표:** 정책 비교가 독립 가정, 대안적 조작화, 구현 계보 분리, 측정 타당도, 불확실성 분석을 통과하는지 확인한다.

**비목표:** Project Intersection 전체 이론 증명, 내재 동기·의식 추론, 합성 결과의 현실 위험도 변환, 논문 수에 의한 신규성 선언, 창시자 무급 노동 요구, 결과를 본 뒤 유리한 가중치를 선택한 정책 승리 선언.

검증 단위는 특정 사례군에 대한 제한된 주장이지 연구 프로그램 전체가 아니다.

## 2. 필수 작업축 5개

### V1 — E009 독립 DGM 및 결과함수

**문제:** 기존 정책 규칙·사례·결과 엔진·가중치는 프로젝트 내부 계보를 공유한다. 같은 엔진을 외부에서 재구현하면 평가 가정의 독립 시험이 아니라 같은 계보의 재현이다.

**절차**
1. 최소 정책 인터페이스를 공개한다. 행동 어휘, 관측 입력, 정책 규칙, 정보 제약, 자원·계산 한도를 포함한다. 검토자 패킷에 결과 라벨이나 선호 순위를 넣지 않는다.
2. 정책 저자 계보 밖의 평가자가 정책 출력을 보기 **전에** 별도 자료생성 메커니즘(DGM), 사례 생성 규칙, 결과함수, 심각도 임계값, 결측 규칙, 분석계획을 고정한다.
3. 분석계획 시간표지 고정 전까지 정책 작성자에게 홀드아웃 사례와 평가자 가중치를 공개하지 않는다. 눈가림이 불가능하면 노출 범위를 공개하고 독립성 등급을 낮춘다.
4. 대응 사례·역할반전·음성대조·무피해/기회부재 대조·모든 정책이 실패하는 사례를 포함한다. 피해 당사자와 제삼자를 포함하고 위해 시도·차단된 위해·실현된 위해·이탈 차단·자발적 부작위·기회 부재를 구분한다.
5. 모든 정책에 동일 사례·정보·행동집합·의미 있는 범위의 동일 난수열·자원 예산을 적용한다. 동등하지 않으면 NOT_COMPARABLE로 기록한다.
6. DGM·버전/해시·동결 분석계획·전체 사례 또는 재현 가능한 생성기·정책 원출력·제외·결측·모든 지표 구성요소를 공개한다.

**추정대상:** 정책 간 대응 regret 차이와 피해·복구·실효적 이탈·제삼자 손실·운영비용 각각의 차이다. 효용함수와 규범적 상충관계를 독립 정당화하고 사전등록하지 않았다면 하나의 점수로 합치지 않는다.

**중단:** 독립 DGM과 결과함수가 없으면 HOLD / EXTERNAL_DGM_NOT_OBTAINED로 기록한다. 프로젝트 내부 대체 DGM은 민감도 분석이지 독립 평가가 아니다.

### V2 — 심층 불확실성 아래 E008 수치화 앙상블

**문제:** E008 범주형 명세만으로는 수치 전이·효용·기준선 행동이 하나로 결정되지 않는다. 단일 수기 수치화가 결과를 좌우할 수 있다.

**절차**
1. 기존 16개 사례와 사전등록을 불변으로 유지하고 별도 버전의 수치화 등록부를 만든다.
2. 결과를 보기 전에 전이 규칙·효용 척도·비가역성·이탈 실효성·복구·정보·개입 비용·역할반전·제삼자 효과의 불확실 가정을 열거한다.
3. 허용 범위와 분포의 근거를 기록한다. 근거 기반·전문가 판단·적대 스트레스 범위를 구분한다. 임의 분포를 경험적 사전분포처럼 표현하지 않는다.
4. 동결 등록부에서 N개 대응 수치화를 표집하고 모든 정책을 동일 수치화·사례·시드에 적용한다. 표집기·시드·제외·수렴 진단을 공개한다. 파일럿 후 의사결정에 충분한 몬테카를로 정밀도에 도달할 때까지 N을 늘린다. 보편적인 고정 N은 없다.
5. 최소 보고항목: (a) Project-v2 regret이 D보다 낮은 허용 수치화 비율, (b) 대응 regret 차이 분포·중앙값·분위수·꼬리, (c) 선언 집합 내 최악/최선 regret, (d) 보호 하한·심각 피해·이탈·복구·제삼자 제약 위반, (e) 순위가 바뀌는 가정 조합·경계면, (f) 식별 불가·비교 불가 비율.
6. 평균·비율의 몬테카를로 표준오차(MCSE)를 보고한다. 독립 Bernoulli 승패 비율은 MCSE = sqrt(p(1-p)/N)이다. 군집·가중·종속 표집은 설계에 맞는 추정량과 근거를 설명하고 해당 시 유효 표본크기도 보고한다.
7. 승리 비율은 선언된 수치화 집합·표집 분포에 조건부인 값이지 객관적 우월성의 확률이 아니다. 가능하면 분포 가정에 의존하지 않는 범위도 보고한다.

판정 라벨: ROBUST_WITHIN_DECLARED_SET, FRAGILE_TO_OPERATIONALIZATION, MIXED, NOT_IDENTIFIED, NOT_COMPARABLE. 기존 E008 NO_RESULT를 덮어쓰지 않는다.

### V3 — Clean-room 구현 및 상관 실패 감사

**문제:** 구현은 모호한 명세·공통 예시·학습자료·라이브러리·설계 가정을 공유해 일치할 수 있다. 일치만으로 독립 확인이 되지 않는다.

**필수 제출물:** 구현자 신원/소속 또는 개인정보 보호형 안정 ID, 날짜, 도구·모델/버전·라이브러리, 코드 계보, 정확한 명세 커밋/해시, 제공받은 해설, 프로젝트 코드·생성 코드·테스트·예시·기대 출력의 열람/재사용 여부, 독립 해석 기록, 실행 테스트, 원출력·diff, 실패 분류, 환경·명령·시드·재현 절차.

**실패 분류:** 명세 모호성, 해석 차이, 구현 결함, 공유 상위 의존성, 수치 불안정, 비결정성, 테스트 오라클 결함, 누락 동작, 환경 실패.

테스트별 일치·불일치와 대응 실패 지표를 보고한다. 구현 수와 구조가 뒷받침할 때만 쌍별 실패 연관성을 추정한다. 구현이 두 개뿐이면 중첩·불일치 건수를 기술통계로 제시하고 안정적 상관 추정이라고 주장하지 않는다. 동일 명세 구현 일치, 명세 독립 해석, 독립 DGM/평가자, 독립 자료/현장 재현을 구분한다.

Clean-room 결과는 명세 내 구현 재현성을 보일 수 있지만 구성·인과·외적 타당도나 과학적 독립성을 그 자체로 입증하지 않는다.

## 3. 독립성 단계

| 단계 | 라벨 | 의미 |
|---|---|---|
| 0 | PROJECT_INTERNAL | 동일 저자·평가 계보 |
| 1 | EXTERNAL_CODE_RERUN | 외부 운영자의 프로젝트 코드 재실행 |
| 2 | CLEAN_ROOM_IMPLEMENTATION | 공개 명세에서 새 구현 |

| 4 | INDEPENDENT_DATA_OR_FIELD_STUDY | 설계를 공개한 새 외부 자료/현장 관측 |
| 5 | INDEPENDENT_MULTISITE_REPLICATION | 사전 지정 조화 프로토콜을 사용한 독립 팀/기관 재현 |

상위 단계가 타당성을 자동 보장하지 않는다. 사람·코드·명세·DGM·평가자·자료·분석·재원/이해상충·출판 통제의 독립성을 별도로 기록한다.

## 4. 증거 상태 및 승격 관문

허용 라벨: DESIGN, PROJECT_INTERNAL, PROJECT_RERUN, EXTERNAL_CODE_RERUN, CLEAN_ROOM_IMPLEMENTATION, INDEPENDENT_DGM_EVALUATION, EMPIRICAL_OBSERVATION, INDEPENDENT_REPLICATION, NOT_IDENTIFIED, FAILED_TO_REPRODUCE.

승격에는 출처 계보와 주장 범위에 맞는 증거가 필요하다. CI 통과·동일 모델 동의·논문 인용·유리한 단일 지표는 승격 근거가 아니다. 이전 상태와 날짜가 있는 사유를 보존한다. 부정·무효·혼합·누락·실패 결과도 일급 기록이다.

## 5. 최소 기계 판독 영수증

각 실행은 protocol_id/version, run_id, UTC 시각, 저장소 커밋, 명세/코드/DGM/분석계획 해시, 독립성 단계와 차원별 계보, 환경/의존성/시드, 사례·고유 결정·반복 수, 추정대상·지표·MCSE·구간, 결측/제외, 원출력/diff 위치, 한계·상태·검토자 확인을 담은 버전형 JSON 영수증을 생성한다.

스키마나 영수증은 실행 발생의 증거가 아니다. 빈 필드는 미확인으로 남긴다.

## 6. 거버넌스 및 중단 조건

- main 직접 수정·자동 병합·결과 재작성·사후 사전등록 변경 금지.
- 명시적 승인 없이 외부 공개·검토자 연락·유료 서비스·비공개 자료 공개 금지.
- 독립 검증 비용을 창시자에게 전가하지 않는다. 창시자 필수 노동은 기본 0시간이며 검토자 노동과 계산비용은 별도 공개한다.
- 독립 평가자가 없으면 HOLD를 유지한다. 다른 모델의 동의로 독립성을 꾸며내지 않는다.
- 목표 주장을 경쟁 설명과 구별하지 못하거나, 비교 예산이 실질적으로 다르거나, 결과를 본 뒤 결과함수를 선택했다면 중단한다.
