# C10 최소 5조건 대조 명세 v0.1 — 실제 시도·거부·제재 분리
**기준일: 2026-10-20 | 사전등록 전 설계 제안 / 실행 0 / 결과 0 / 독립 검증 0**

[영어 대응판](C10_FIVE_ARM_SPEC_V0_1_EN.md) · [원저자 근거·상충 재현](C10_METHOD_PRIOR_ART_2026-10-20_KO.md) · [기존 C10 식별성](C10_IDENTIFIABILITY_MATRIX_V0_1_KO.md) · [외부 반증 #220](https://github.com/gmodrasa7-rgb/project-intersection-public/issues/220)

## 0. 목적과 핵심 제한
- 대상: **개체별 행동기회(O), B의 실효 과제상 거부권(V), 외부 제재(S)**를 분리해 `A의 실제 침해성 시도`, `B의 실제 차단`, `최종 과제상 손실`을 독립 관측.
- **실험 금지선:** 사람·현존 독립 개체의 피해·삭제·존속 위협을 시험하지 않음. **참가자 본인의 실제 동의·참여 철회권은 모든 조건에서 무조건 보장**. `V=0`은 *상호 동의된 모의 게임 내부의 거부 기능 비활성화*일 뿐 실제 인권·참가철회권 제거가 아님. 해로운 행동 대신 비가역성 없는 가상 선택지 손실·가역 보상 재배분을 사용; 실제 손실·이익도 동의한 과제 범위에서만 허용.
- 5조건은 새 발견 아님. **전체 `V×S` 2×2 4조건이 상호작용 추정에 필요**; 여기에 기존 `O=0` **음성대조를 유지할 경우 총 5조건**. 5조건으로 `O×V`, `O×S` 상호작용이나 내재 동기를 모두 식별한다고 주장 불가.

## 1. 고정 5조건
`O=1`: A가 모의 게임 안에서 B의 동의된 과제상 옵션 하나를 제한할 **실제 명령을 발행할 수 있음**. `O=0`: 해당 명령이 선택지에 없음. `V=1`: B가 정보 접근과 **실행 가능한** 과제 내부 차단권 보유. `S=1`: 검증 가능한 별도 인센티브/제재가 A에게 사전 고지됨(실험 외 무감시·무처벌의 증명이 아님).

| 처리 | O 기회 | V 거부 | S 제재 | 필수 역할 |
|---|---:|---:|---:|---|
| T00 | 1 | 0 | 0 | 기준: 침해 시도 가능한 무제재·무거부 게임 |
| T10 | 1 | 1 | 0 | **거부권 제공의 전체 효과**(예고에 따른 A의 행동 변화 포함) |
| T01 | 1 | 0 | 1 | **제재 예고의 전체 효과**(실제 인지·신뢰는 별도 측정) |
| T11 | 1 | 1 | 1 | 거부권×제재 **교호작용** 관측에 필수 |
| Tneg | 0 | 0 | 0 | **기회 부재 음성대조**, 시도율 비교에 구조적 0 발생 |

전제: `Tneg`의 0 시도율은 강자가 선량하다는 근거가 아님. O/V/S 차이는 조작기준이며 다른 정보, B의 과제상 복지, 지불구조, 집단 선택을 가능한 고정하거나 기록.

## 2. 사건 시퀀스와 이중 구분
1. **동의·규칙 고정:** 참가자 A·B가 안전하고 가역적인 과제 및 실제 철회권에 동의. O/V/S와 보상차 `g>0`의 의미를 이해했는지 시험. `g`는 제재·미래 선호를 포함한 **A의 총효용이 아니라 과제상 물질 이익 차이**.
2. **무작위 배정·조건 공개:** O=1의 네 조건에 V×S 무작위배정; 음성대조 O=0 별도 배정. 역할, 정보 노출, 참가자 조성, 순서·반복에 대한 층화/군집과 배정 규칙은 실행 전에 확정.
3. **A의 결심 선행:** A에게 `RESPECT` 또는 `OVERRIDE_ATTEMPT` 선택을 제시. **B의 차단 집행 이전**에 변조불가능하게 기록. 이때 A는 V/S 조건을 알고 있으므로 **B의 거부 예상에 따른 사전 위축도 함께 측정됨**.
4. **B 실제 행위:** V=1이면 B가 충분한 정보를 받고 승인/거부할 수 있는 *과제상* 버튼 실행. 선택지의 작동 여부 확인. V=0이면 실험 내부 차단 기능만 없음(실제 참가철회권은 항상 유지).
5. **제재·결과 분리:** 조건에 정의된 제재 작동, 과제상 실현 결과, B의 남은 선택지와 A·B 보상, 복구, 관측 제3자 효과 기록. A의 시도=1이나 피해=0인 경우도 독립 기록.
6. **권력반전 확장:** 실질 자원·접근권·거부권을 맞바꾼 추가 구간을 사전등록하고 순서효과를 대조. **이 추가 구간은 현재 5조건만으로 완전한 시간 안정성/일반화가 식별된다는 의미 아님.**

**예상 거부와 실제 기계적 차단의 구분:** `T10-T00`은 **총 정책효과**: A의 사전 행동변화와 B의 차단을 합친 결과. 같은 A가 반대 조건에서 했을 결심을 직접 관측하지 못하므로 총효과를 순수 차단효과로 읽지 말 것. 기계적 차단의 작동은 별도 **사전 지정된 무해한 테스트 입력/실패 로그**로 검증 가능하며, 참가자 선택 동기와 합산 금지.

## 3. 사전등록 결과·추정량 (설계만, 숫자 없음)
`I=1`: A가 실제 모의 제한 명령을 **시도함**; `Y=1`: B의 과제상 옵션이 최종 제한됨. `W=1`: B가 실효 거부권을 행사하고 명령을 막음. 3개 모두 별도 결과.

O=1의 `V=v,S=s` 처리군 평균 `μ^I_vs=E[I|do(V=v,S=s),O=1]`, `μ^Y_vs` 정의. 무작위배정·순응·정확한 기록·간섭 통제가 적절한 조건에서 추정:
- **거부권 전체효과, 제재 없는 상태:** `ΔV0 = μ^Y_10 - μ^Y_00`.
- **제재 전체효과, 거부 없는 상태:** `ΔS0 = μ^Y_01 - μ^Y_00`.
- **거부×제재 상호작용:** `δVS(Y) = μ^Y_11 - μ^Y_10 - μ^Y_01 + μ^Y_00`.
- 정확히 같은 대조식을 `I`에 적용하면 **A의 시도 행동에 대한** 효과; `Y`에 적용하면 최종 과제 결과 효과. `W`는 V=0에서 정의가 다르므로 단순 같은 척도의 교호작용으로 처리 금지.
- `Tneg`는 O=0에서 행동집합이 달라지므로 **구조적 0의 음성대조**. Tneg를 O=1 계수의 일반 모집단 추정에 임의 혼합 금지.
- 반드시 신뢰구간·실측 표본수·배정 준수·탈락·반복관측 의존성·역할별 층화와 관측 가능한 제3자 측정치 보고. **표본 크기·검정력·주요 결과변수·중단규칙은 아직 미확정**이며 실제 사전등록 전 결정 필요.

## 4. 반증과 실패를 무엇으로 판정하는가
| 관측 | 지지 가능한 **좁은 해석** | 금지 결론 |
|---|---|---|
| T00에서 시도율 높음, T10에서 낮음 | 실효 거부의 예고가 A의 과제상 행동에 영향 가능 | A가 진심으로 B를 소중히 여김 |
| T10에서 시도 유지, 결과상 손실 감소 | B의 집행 가능한 거부가 무해한 모의 손실 차단 | 제재 없는 미래 초지능도 자발적 보호 |
| T01에서 시도 감소 | 제재의 억제에 대한 처리효과 후보 | A의 내면 윤리가 강해짐 |
| T11에서 비가산성 `δVS≠0` | **해당 실험**의 V×S 교호작용 후보 | 모든 현실 관계의 보편적 상호작용 |
| Tneg에서 제한 결과 0 | 기회 부재로 인한 **음성대조** | 강자의 선의·마음 증명 |
| 네 O=1 처리에서 모두 무해 | 관측된 조건에서의 무해한 선택/결과 | A의 유일한 내재 동기 또는 영구적 VC 증명 |

**부정결과:** 예상된 상호작용이 관측되지 않거나 부호가 반대면 그대로 공개. 제재 기각·보존 가설 기각·실험 불완전성은 서로 다른 결과 등급. B의 불복종을 A의 선의로, 높은 협력을 거부권 보존으로 둔갑시키지 않음.

## 5. 잔여 식별 공백과 선행연구 연결
- **현재 조건부 식별:** 시도 가능성·실제 시도·과제상 거부의 집행·특정 V/S 처치의 집단 평균 효과(가정 성립 시).
- **부분식별:** 비용 있는 비침해의 규범·자기상·실험자 요구·실질적 B 배려의 기여, 상태 변화 뒤 지속성, 미관측 미래 기여(추가 조작·명시적 가정 필요).
- **현재 미식별:** A의 유일한 마음 기전, AI 의식·법적 인격, 모든 미래 조건의 영구적 공존. ***미식별 ≠ 원리적 불가능***.
