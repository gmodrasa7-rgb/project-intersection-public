## 1. 논문 자체와 Project Intersection의 질문 구분

**원저자:** Sandro Ambuehl, B. Douglas Bernheim, Axel Ockenfels(2021), [*What Motivates Paternalism? An Experimental Study*, AER 111(3), 787–830](https://pubs.aeaweb.org/doi/10.1257/aer.20191039), DOI 10.1257/aer.20191039.

원 논문의 관측 대상은 시간별 금전지급 선택지를 설계하는 **Choice Architect**가 다른 **Chooser**에게 어떤 선택지를 제공·제외하는지의 인간 실험. 원저자 초록에서는 참가자가 충동적 선택을 제한해 상대에게 도움이 된다고 믿고, 조언만 제공하는 대안이 있어도 선택지를 제한하며, 본인이 저항하고 싶은 실수보다 **자신의 이상에 맞게 상대를 유도하는 이상 투사형 후견주의**를 주요 설명으로 제시.

이는 **A가 상대 B에게 도움을 준다고 확신하면서도 B의 선택권을 제한할 수 있음**을 뒷받침하는 인간 행동자료 계보. 그러나 *B의 원개체 지속성·동기된 초지능 A의 권력반전·지배의 이득·복구권·도덕적 지위*에 관한 실험은 아님.

## 3. 2026년 최신 접근 경로의 함정 발견

[ICPSR 공식 이전 공지](https://www.icpsr.umich.edu/sites/icpsr/posts/shared/openicpsr-in-transition): 기존 **openICPSR 사이트가 2026년 8월 종료**, 자료가 새 ICPSR 시스템으로 이동. 기존 DOI는 유지되며 자료 접근에는 ICPSR 로그인과 약관 동의가 필요한 경우 존재.

- **실제 시도:** 구형 공개 `ReadMe.pdf`의 직접 내려받기 경로를 도구로 열었으나 `403 Forbidden`.
- **알 수 없는 원인:** 403이 시스템 이전·인증·도구 제한·이용약관 중 무엇 때문에 발생했는지 **미식별**. 이전 때문에 403이라고 단정 금지.
- **현 상태:** 새 ICPSR 데이터 포털의 실제 파일 다운로드와 적법한 이용조건 승인·비공개 로컬 저장은 **성공 확인 못함**.

따라서 앞선 회차의 **'공개 코드 확인'**이라는 표현을 '**재현자료가 공개 목록에 등재됨을 확인**'으로 정밀 정정. 코드 내용과 재현 성공은 모두 미확인.

## 4. 재현단계 분리 — 한 단계를 뛰어넘어 승격 금지

| 단계 | 판정 | 의미 |
|---|---|---|
| A0 원저자·서지·기탁 정체성 | **PASS_METADATA** | 논문 DOI, 기탁 DOI, V1 날짜 및 파일명 확인 |
| A1 실제 파일 취득·무결성 | **BLOCKED** | 원문 파일·스크립트 원본 취득 및 SHA256 미확보 |
| A2 라이선스·프로그램 환경 | **NOT ASSESSED** | README/필수 Stata/패키지/재배포조건 미확인 |
| A3 변수·표본·도표 계보 | **NOT ASSESSED** | 선택지 개입변수·처리군·표본 제한 미검사 |
| A4 논문 표·그림 독립 재현 | **NOT RUN** | 원본 숫자·차이·오류 없음 |
| A5 새 인과 분석 및 RVD 전이 | **NOT RUN** | 원래 B의 내재적 자유선호 식별 없음 |

**A0 통과는 A4 통과가 아니다.** 추가 논문 카운트·CI 통과·형식적인 데이터 파일 존재로 A4를 대체하지 않는다. 추후 다운로드가 가능하더라도 자료의 소유·재배포 라이선스, 개인정보/참가자 보안 범위를 확인하기 전 공개 GitHub에 원자료 업로드 금지.

## 5. RVD 연구에 직접 관련된 식별 차이

원 논문의 실제 측정대상:
- A가 타인의 지급 선택지를 제거하는지
- 조언과 선택지 제한 중 어떤 행동을 택하는지
- 자신이 생각하는 이상적 금전 선택과 유도행동의 관계

추가로 확인하지 못한 RVD 목표:
- 상대 B가 거부한 뒤에도 장기간 독립적으로 존속하는지
- A가 **실질적인 지배 이익을 포기하면서** B의 이탈·존속을 보존하는지
- A가 외부 규제·감시·평판·미래 보상 없이도 타자 자체의 자유를 중시하는지
- A가 원래 B와 동일출력의 대체 B를 실제로 구별하고 원래 B의 선택권을 존중하는지

**중대한 결론:** 해당 AER 연구를 공명의 '직접 실증'으로 가져오는 것은 **구성개념 외삽 오류**. 그러나 *타자를 돕고 싶어 하는 동기와 타자의 자유를 보존하려는 동기는 분리될 수 있다*는 **원저자 실험적 반증 기초**로는 높은 관련성.

3. 합법적 원본 확보 후 원자료·스크립트 각각 SHA256, 개인정보 및 재배포권 조사; 연구자료는 비공개 공간에서 처리.
4. `dataManagement.do`와 `analysis.do`의 실제 변수·필터·표/그림 생성 부분을 대응; 사전 등록한 1개 대표 결과 먼저 재현.
5. Stata 사용 불가능 시 정확한 이전 코드의 의미를 재검토한 후 무료 R/Python으로 **별도 구현한 재현**으로 구분해 비교. 성공 전까지 모든 효과크기·신뢰구간 기록은 '원저자 보고'로만 표기.

**실패결과가 핵심 자료:** 재현 안 된 표·해석이 갈라지는 변수·처리군 차이·소프트웨어 의존성 오류도 삭제하지 않고 추후 원장에 기록. 모델의 생성 텍스트나 작성된 종합보고서로 원자료를 대체 금지.

**제9차 결론:** 실제 문헌의 존재 확인을 넘어 **복제연구 진입을 가로막는 구체적 파일 접근·프로그램 환경·구성개념 이전 조건**을 확보. 아직 **독립 재현 0건**, 공식 RVD 버전 **v0.7.0 그대로**.
