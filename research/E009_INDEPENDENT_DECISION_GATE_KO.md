# E009 — 외부 독립 판단을 위한 단일 검증 과제

**원본 2 — 한국어 | 2026-10-15 | 외부 검증 요청 / 신규 실험 결과 없음 / 독립 검증 미확보**

## 검토할 질문 하나

**프로젝트 외부에서 독립적으로 결정한 사례·결과함수·비용 기준에서도 PROJECT_V3가 TWO_RULE_SIMPLE 및 MINIMAL_4VAR보다 심각한 피해, 실효적 이탈 상실, 제삼자 비용, 평가비용을 증가시키지 않으면서 추가적인 의사결정 가치를 제공하는가?**

이는 자발적 공존 전체의 옳고 그름이 아니라, **복잡한 정책의 증분 성능**에 대한 반증 가능 질문이다.

## 기존 부정결과 고정

기존 E009 자료: [결과](../experiments/e009/RESULT_KO.md), [동결 코드](../experiments/e009/benchmark.py), [실행 영수증](../experiments/e009/EXECUTION_RECEIPT.json). 프로젝트 자체 합성 스트레스 실험의 평균 regret은 TWO 0.063241, M4 0.065323, V3 0.090022였고, V3는 사전등록 생존 기준 **4개 중 3개에 실패**했다. 기존 [복잡성·난수·사례군 민감도 분석](../experiments/e009/README.md) 역시 프로젝트 내부 계보의 합성 분석이다.

**현재 결정:** 이 벤치마크에서 V3의 복잡한 추가 구조는 **지지되지 않는다**. 단순 2규칙과 최소 4변수를 기본 비교 대상으로 유지한다. 기존 E009 코드를 사후 조정하거나 부정결과를 덮어쓰지 않는다.

## 과제 A — 외부인의 기존 코드 재실행

```sh
git clone https://github.com/gmodrasa7-rgb/project-intersection-public.git
cd project-intersection-public
git rev-parse HEAD
python experiments/e009/verify_result.py
```

외부 검토자는 커밋·Python 버전·실행환경·실제 출력 및 불일치 내용을 [기존 E009 검토 이슈 #26](https://github.com/gmodrasa7-rgb/project-intersection-public/issues/26)에 기록한다. 동일 프로젝트 코드를 실행하는 것은 **계산 재현**이지 결과모형의 독립성이나 현실 타당성 증명이 아니다. 재실행 실패도 유효한 결과로 기록한다.

## 과제 B — 프로젝트와 독립적인 평가 가정·미공개 사례 (현재 미실행)

외부 검토자가 세 정책의 시험 출력을 **보기 전**에 독자적으로 확정하고 시간표지를 남겨야 할 사항:

1. **새 사례**의 포함 기준, 관련 당사자, 실행 가능한 선택과 각 정책에 허용할 정보량. 가상 사례 또는 개인정보 보호가 가능한 출처 기반 사례를 쓴다. 현실에 위해를 가하는 개입 금지.
2. 독립적인 결과함수. **행동/부작위 피해**, 중대 위해 임계치, 가역성, 복구, 실효적 이탈, 당사자·제삼자 손실, 실제 계산·운영 비용을 포함한다. 미관측치는 0이 아니라 UNKNOWN으로 기록한다.
3. V3·TWO·M4에 동등한 상황·선택·정보·자원 예산을 적용한다. 불가능하면 **NOT_COMPARABLE**로 판단한다.
4. 주요 성능지표, 개인별 위해 허용조건, 동점·누락·거부 처리, 중단조건을 **결과 전**에 고정한다.

사양을 외부 커밋 또는 공개 검토 가능한 사전등록으로 고정한 뒤, 포함된 **모든 결정과 불확실성**을 보고한다. 독립적으로 제작한 새 합성 결과함수는 내부 가정을 깨는 데 유용하지만 **현실 실증과는 다르다**. 기존 사양의 독립 구현, 독립 합성 환경, 현실 사례의 인과분석도 서로 다른 증거등급이다.

## 성과 부풀리기를 막는 최소 제출표

| 항목 | 제출해야 할 증거 |
|---|---|
| 독립성 | 검토자·코드 계보, 기존 E009 정답 인지 여부, 모델/공급사 관계, 프로젝트 코드 재사용 여부 |
| 사전 고정 | 결과 관측 전 사양 링크, 선택한 사례, 비교 조건, 비용·지표·중단기준 |
| 성능 | V3−TWO 및 V3−M4의 동일사례 대응 비교, 분모와 불확실성 |
| 위해·복구 | **고유 의사결정 단위**의 심각 피해 건수, 피해 당사자, 복구·이탈·제삼자 비용 |
| 추가 부담 | 실제 추론비용·검토시간·기여자 노동. 복잡한 정책에 공짜 가산점 금지 |
| 전체 기록 | 사전 선택한 전 사례, 응답누락, 제외사유, 불리한 결과 |
| 결론 | `SIMPLE_BASELINE_PREFERRED`, `V3_LOCAL_INCREMENT`, `MIXED`, `NOT_COMPARABLE`, `REPRODUCTION_FAILED` 중 근거를 붙여 선택 |

**부분적 개선을 전체 성공으로 바꾸지 않는다.** 평균 regret이 줄어도 중대 피해 증가·강제된 동의·이탈 봉쇄·제삼자 손실이 발생하면 이를 별도 상충 결과로 공개한다. 신규 외부 결과가 원래 E009의 부정적 판정을 소급 변경하지 않는다.

## 승격·중단 규칙

- 외부 결과 제출 전에는 **EXTERNAL_VALIDATION = NOT OBTAINED**. 검증 요청 게시나 다른 AI의 동의는 독립 복제가 아니다.
- 새 비교에서도 단순 정책의 성능이 동등 이상이며 비용이 적다면 **그 범위에서 단순 정책 유지**, 입증되지 않은 추가 변수를 비활성화한다.
- V3가 독립 고정된 조건에서 우세하면 **해당 조건만의 제한적 추가 가치**를 기록하고, 별도 재현 전에는 일반 이론으로 승격하지 않는다.
- 비교가 불가능하거나 외부 검토자가 없다면 **UNRESOLVED**로 중단한다. 연구자의 반복 무급 검증노동으로 공백을 메우지 않는다.
- 유료 API·과금 가능한 CI·지원금 지급 약속·비공개 자료 접근·창시자 추가 노동 요구 없음.
