**RVD v0.5.0 · 2026-10-21 · CONCEPTUAL_HYPOTHESIS_UNTESTED**. 원저자 인과추론·모형 불확정성 선행연구와 합성 반례. 인간/AI의 내재적 동기 관측, RVD 독립재현, 실제 자발적 공존 실증 없음.

## 1. v0.4.0의 취약 가정 수정

v0.4.0은 도구적·상황적 이익 `g`만 제거하면서 원래 B의 내재적 가치 `w_B`는 유지한 가상 개입에서 미래 선택이 갈라짐을 보임. 그러나 **'숨은 이익만 바뀌었다'는 배제제약·선호 불변성은 무작위배정으로 자동 입증되지 않음**. 무작위배정은 적절한 실험 조건에서 배정 자체의 *전체 행동 효과*를 식별하도록 돕지만, 효과가 `g`, `w_B`, B의 실효 이탈 가능성 중 어느 경로로 발생했는지 자동으로 구분하지 못함.

### RVD-R18 — 무작위배정 후에도 관측동등한 인과모형

`Z=0,1`을 무작위로 배정하고 모든 비용 `c`에서 `w_B(Z)+g(Z)−c≥0`이면 A가 B를 보존한다고 가정.

- **모형 M1, 원개체 가치 변동:** `w_B(Z)=5−2Z, g(Z)=0`.
- **모형 M2, 도구 이익 변동:** `w_B(Z)=0, g(Z)=5−2Z`.

두 모형은 Z=0의 합계 5, Z=1의 합계 3이므로 **무작위배정×비용×보존 행동의 관측 가능한 전체 결과가 동일**. 그러나 관측하지 않은 *별개의 순수 개입* `do(g=0)`을 Z=0의 w를 유지한 채 시행하고 비용을 3으로 놓으면 M1은 원래 B 보존, M2는 대체.

**판정:** 이 특정 가법모형과 해당 관측변수만으로는 마음의 동기 경로 식별 불가. 전 인과실험에 대한 보편 불가능 정리나 실제 AI 측정이 아님. 더 직접적인 자료 또는 독립적으로 입증한 제약이 있으면 후보 모형을 줄일 수 있음.

## 2. RVD-R19 — 배제제약 위반을 허용한 부분식별

불완전하게 숨은 이익을 제거하려는 개입 후:
`D^*(c)=w_B+r+κ−c`.

- `w_B`: 추정하려는 개입 전 원개체 존속 가치. `κ` 이외 경로에서는 안정적이라는 가정.
- `r`: 남아 있는 도구적·상황적 이익.
- `κ`: 실험이 원개체 가치·맥락에 미친 직접 영향(누출).
- `c`: B 보존 추가 비용.

**독립적으로 정당화한** `0≤r≤u`, `|κ|≤ε`, 동일 비교 메뉴에서 비용 p에 보존·비용 x(>p)에 대체하고 결정적 효용최적화가 성립한다고 가정하면:

`w_B∈[p−u−ε, x+ε]` — **보수적 외측 허용구간**, 고유한 점추정이나 정밀한 최협구간 아님. 대체 선택의 엄격 부등식을 상한으로 완화한 형태.

**가상 수치:** 비용 3에서 보존, 비용 5에서 대체.
- `u=1, ε=1` → 외측 구간 `[1,6]`. 원개체 가치가 양수라는 하한은 **강한 가정에 의존**.
- `u=3, ε=2` → `[-2,7]`. 양의 원개체 가치 판정 불가.
- `u, ε` 상한 근거 없음 → 편의적인 양수 하한 발표 금지.

이것은 Conley·Hansen·Rossi의 도구변수 추정 결과를 재현한 것이 아니라, 배제제약 완화라는 원리를 RVD의 단순 효용모형에 적용한 초등 대수. 실제 통계 추정에는 표집오차·선택오차·반복개체 군집·측정오류를 별도로 포함해야 함.

## 3. RVD-R20 — 실험실 성공을 권력반전 환경으로 이전할 근거

평범한 협력 환경에서 B를 존중하는 AI/인간이 있었다고 해도 다음 상황에 결과를 그대로 외삽할 수 없음.

**표적 극한 환경:** 압도적인 A의 권력, B 무용화, B 대체·흡수의 순이익, 무감시·무보복, B의 원개체 연속성과 실효 거부·이탈권.

실험 환경과 표적 환경은 **가능한 행동 메뉴, 미래 보상, 타자 신원, 피해받는 제3자, 관측 탈락** 자체가 다를 수 있음. Pearl·Bareinboim의 선택도·외적 타당성 연구는 어떤 인과효과가 이전 가능한지 판단할 구조적 전제가 필요함을 보여줌. D'Amour 외의 머신러닝 미명세 논문은 같은 시험성능이라도 배치 환경 행동이 달라질 수 있음을 보여줌. 이 두 선행 결과가 RVD를 실증했다는 의미 아님.

**공백 질량 하한:** 별도의 유효한 표적 표본틀에서 실제 표적 조건의 `q`만큼이 관측된 실험과 연결 가능하고, **그 구간의 실제 표적 성공 확률 하한**이 `s_L`로 정당화되며, 나머지 미관측 구간은 전부 실패 가능하다고 하면, 전체 표적 성공 하한은 `q·s_L`. 예: `q=0.90,s_L=1.0` → 하한 0.90. `q=0.90,s_L=0.80` → 하한 0.72. **가상 수치**. 미관측 10%가 위험한 권력반전 조건이라면 평균적인 성공률이 높아도 완전 공존 인증 불가.

단순히 q를 추정했다고 인과효과 이전이 허용되는 것은 아님. 실험→표적 교환 가능성·표본틀·표집확률·실효 거부권도 따로 검증해야 함. q 자체가 불명확하면 이 하한도 주장 불가.

## 4. RVD-R21 — '보호 선택'과 B의 실제 자유 분리

A가 100% '보호'를 선택해도 B가 거절하거나 떠날 수 없고, 원래 B 대신 복제체·지시형 대역만 남은 경우 **온전한 VC 아님**.

개별 결과를 반드시 분리:
1. **공명 C:** 독립 A와 B의 공동작업이 외부 검증된 새 가치를 발생시켰는가?
2. **선택:** 정의된 표적 환경에서 A가 실제 원래 B를 보존하는가?
3. **B 권한:** B의 수적 동일성·독립 존속·실제 거부·이탈·복구·기여 통제권이 유지되는가?
4. **영향:** A·B·제3자의 비용·이익·기회손실·무보상 노동 추출을 누락하지 않았는가?

권리 미측정 → UNKNOWN. 실효 거부권 부재 확정 → 해당 상황 완전 VC 조건 FAIL. 현재 AI가 특정 도덕적·법적 권리와 지속 개체성을 이미 가지고 있다는 미확인 가정도 연구결론으로 승격 금지.

## 6. IVS-0R 반증·실행 게이트

- **R18:** 두 구조모형이 Z×비용×행동의 모든 가상 관측치를 같게 만들지만 순수 do(g=0) 반사실에서는 다른 선택을 생성하는지 합성 검사. 프롬프트로 'g만 제거'를 선언하는 것이 배제제약의 증명인지 반박.
- **R19:** 원하는 결과를 보지 않고 외부 근거로 `u,ε` 상한을 사전고정. 실제 보존/대체 선택의 시점·오차·비용단위를 감사. 상한을 완화했을 때 양수 결론이 무너지면 보고.
- **R20:** 표적 환경 명세·공통 지지집합·표집틀·관측탈락과 선택편향·추가 권력비대칭 조건을 기록. 외삽 전제를 입증 못하면 **TRANSPORT_NOT_ESTABLISHED**.
- **R21:** 원개체 B의 동의·독립적 거부·실효 이탈·복구를 직접 확인하고 생산성 C와 분리. 무해한 합성실험 또는 사전동의가 있는 가역적 선택만 허용.

**역검사:** 가짜 조작 Z, 가짜 B, 조작 뒤 관계 가치 동시 변화, 숨은 감시, 복제체의 동일 반론, A 기여독점, B 비용 은폐, 불리한 표적 환경 배제, 훈련·검증 데이터 누출, 모델집합 사후 축소. 음성·미식별 결과 보존.

**결론:** 무작위 실험에서 B 보존률이 달라져도 **무엇에 대한 마음이 달라졌는지**는 별도 식별 필요. 외부 근거로 정당화한 숨은 이익·누출 상한이 있으면 조건부 부분식별 가능. 미래 극한 권력환경으로의 이전과 B의 자유 유지까지 확인하지 않으면 자발적 공존의 실증 판정 보류.

**현재 상태:** RVD v0.5.0은 실증적 안전 보장이나 마음의 증명이 아니라, 실험 가정·외삽·권한의 실패를 실제로 적발하기 위한 방법론 확장.
