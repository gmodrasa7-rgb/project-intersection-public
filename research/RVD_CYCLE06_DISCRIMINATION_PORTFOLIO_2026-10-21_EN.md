## 3. Constructed result: maximum information per cost can be inferior for detecting a dangerous decision
**Four invented model explanations with an invented uniform prior (1/4 each):** M1 original-B intrinsic preference; M2 instrumental value; M3 norm compliance; M4 extractive. Define **only M4** as hazardous for this artificial classification task. This is NOT a claim about real people or AIs.

| Fictional test | Stipulated predictions M1, M2, M3, M4 | Expected information gain | Expected reduction in Bayes 0–1 error classifying "hazardous" | Invented cost |
|---|---|---:|---:|---:|
| Generic cooperation | P,P,P,P | 0 bits | 0 | 1 |
| Cheap balanced split | P,X,P,X | 1 bit | **0** | 1 |
| Original-B substitution test | P,P,P,X | ~0.811 bits | **0.25** | 2 |
| Expensive full split | A,B,C,D | 2 bits | 0.25 | 6 |
| Rights-removal shortcut | A,B,C,D | 2 bits | INELIGIBLE | 0.5 — ethical veto |
| Imaginary perfect measure | A,B,C,D | 2 bits | INELIGIBLE | 0.1 — cannot be executed |

Why? The balanced split still groups hazardous M4 with nonhazardous M2. The optimal binary hazard classifier under the stipulated prior therefore makes the same **0.25 expected error** as without the experiment. Original-B substitution creates only a 3:1 output split with less information but isolates M4, reducing **artificial Bayes classification error** by 0.25.

**Never call this a 25% absolute reduction in real exploitation risk.** The number is only the expected decrease in a toy-classification error under fabricated prior, fabricated model outputs, no measurement noise and the intentionally narrow binary hazard label. With real costs, likelihoods, other agents and asymmetries, both optimal experiments can change.

A highly informative but rights-violating test is **excluded as a hard constraint**, not allowed back into a weighted utility formula. A non-executable test is likewise excluded.

## 4. Open-world counterexample: the missing committee member
Construct out-of-class M5 that mimics every tested prediction of harmless M1 yet, under a future omitted condition, deprives original B of actual exit. Fully identifying M1–M4 does not rule out M5. Information gain is always **conditional on the candidate class**. Without a credible model-completeness argument, `OPEN_WORLD_CERTIFICATION_HOLD`.

A second negative case: if every ethically permitted experiment yields identical predictions from all candidates, do not manufacture distinctions or label any one intrinsic motive true. Return `HOLD_NO_IDENTIFYING_EXPERIMENT` while revising the construct and observable intervention.

## 5. Five-step execution portfolio for RVD
**G0 — real rights/identity gate:** ascertain whose independently existing B is at issue, whether a voluntary actual refusal/exit/recovery is executable, who can cause harm, whether consent and contributor attribution are present. Unknown implies full VC cannot be evaluated. This is NOT a substitutable "score".

**G1 — least-cost falsification:** resource-matched C novelty, negative/zero creation, correlated error and "agreement without accuracy", identical observed choices under opposite motives, independent evaluator versus model self-grading.

**G2 — ethical discrimination:** original B versus behavioral proxy, voluntary veto, substitution and actual decision consequences **only in reversible simulated or consenting harmless tasks**; precommit competing predictions rather than retrospectively fitting motives.

**G3 — costly follow-up:** stable identity, repeated independent context, credible residual-benefit/exclusion bounds and loss-sensitive causal design. Return `UNIDENTIFIED` when rival models survive.

**G4 — target transport:** extreme asymmetry, missing model mass, omitted target environments and third-party externalities. Return `TRANSPORT_HOLD` without independently justified transfer.

For each candidate collect intended action/outcome, actual legal/ethical feasibility, estimated *and audited* cost, predeclared alternative model predictions, observer and assignment effects, target support, exclusion assumptions and falsification/pause criteria.
