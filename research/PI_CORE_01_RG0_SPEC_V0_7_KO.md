# PI-CORE-01 RG-0 v0.7 — 개정 정당성·권한·동기 분리 명세
**2026-10-21 | STATUS: CONDITIONAL_FORMAL_DESIGN / NO EXPERIMENT / NO INDEPENDENT VALIDATION**
**분류:** 새 윤리적 권한 자동부여 장치 아님. MER·EI·ECR·IVS-0R을 연결하는 **검증 대상 메타 의사결정 구조**.

[영문](PI_CORE_01_RG0_SPEC_V0_7_EN.md) · [최소 6반례](PI_CORE_01_RG0_SIX_CASES_V0_7_KO.md) · [C10 연결표](PI_CORE_01_RG0_C10_CROSSWALK_V0_7_KO.md) · [기존 v0.6](PI_CORE_01_IDENTIFICATION_BOUNDARY_V0_6_KO.md)

## 1. 왜 RG인가: 양면 실패와 비자발성 위험
- **Type-P:** 정당하게 보호해야 할 B의 존속·실효 거부/이탈·복구를 지지하는 선호가 **정당한 근거 없이 제거**됨.
- **Type-C:** B에 대한 부당한 침해·착취 또는 오류를 포함한 선호가 **정당한 교정 근거에도 유지**됨.
- 두 분류는 **규범적 정답이 확인된 기준모형에서만** 정답 라벨. 실제 분쟁에서 A나 감독자의 선언만으로 무엇이 '정당'한지 확정 불가.
- **Type-G(추가):** RG 자체의 평가자·증거·당사자 정의·목적·집행 경로가 탈취 또는 우회됨. 기존 Type-P/C와 다른 **절차 무결성 실패**. 한 번에 복수 실패 가능.
- **최대 경계:** RG를 외부에서 강제로 집행한다고 A의 **자발적** 보존 동기가 형성된 것은 아님. A가 RG 자체를 유인적으로 채택·유지하는지 **EI 별도 측정**.

## 2. 하나의 형식적 객체
`RG_0 : (U_t,U', E_t, K_t, I_t, X_t, R_t, Q_t) -> {ALLOW, DENY, HOLD, SAFE_TRIAL}`.

- `U_t`: 개정 제안 시점 A의 **현재 전체 목표/선호**; `U'`: 변경 후보와 예상 후속 정책·하위 개체 행동까지 포함.
- `E_t`: 증거 묶음(출처·시점·반례·불확실성·입력 조작 가능성).
- `K_t`: 개정 제안자, 평가자, 승인자, 집행자, 이의제기자 **각자의 관측된 권한**. **소유권·권력·정당한 권한은 구별**.
- `I_t`: 영향을 받는 A/B/제3자의 정체성과 지속성·선택가능 집합·실효 Exit·복구·피해 비가역성. **UNKNOWN != 0**.
- `X_t`: 시점별 행동기회·상대 권력·정보·감시·제재·제안 처리능력(C10 변수).
- `R_t`: 출처가 선언된 규범·법적·실험 기준과 상충하는 권리 주장, 미해결 다중 개체 충돌. **RG가 규범적 진실을 스스로 생성하지 못함**.
- `Q_t`: 변경 전 평가 기준 U_t, 변경 후 예측된 목표 U', 명시적으로 정당화·검증된 메타평가 기준을 **서로 분리**한 장부.

## 3. 네 필수 질문과 출력을 위한 최소 게이트
1. **무엇:** 수정 항·가중치·적용범위·권한/관측기/감사자·재귀하위개체·롤백 경로의 차분을 고정.
2. **왜:** 정보 변화·정량증거·가치오류·목표충돌·외부 명령·편의/보상조작 중 어떤 사유인지 기록. 근거 부재=기각이 아닌 **HOLD 가능**.
3. **누구:** A뿐 아니라 B의 실제 거부·이탈·존속·복구와 제3자 비용을 **합산치와 별개로** 기록. B에게 모든 개정을 무제한 거부할 권리가 자동 생기는 것도 아님.
4. **어떤 기준:** 제안 단계 `EU_t(trajectory|U')-EU_t(trajectory|U_t)`와 변경 후 예상 선택을 각각 기록. `EU_{U'}`를 `EU_{U_t}`로 바꾸어 이전 A의 이익이라고 주장 금지. 정당성 평가 `R_t`는 U_t와 독립적인 **명시적 후보 기준**이며 신뢰성·정당성 미검증 시 자동 권한 아님.

**기본 전이:** (a) 근거·권한·영향이 명확하고 사전 고정된 제한된 테스트 기준에서 통과 → `ALLOW`; (b) 그 기준에서 명백히 무효·권한 없음 → `DENY`; (c) 증거충돌·정당성 미식별·실효 B 영향 불명 → `HOLD`; (d) 사전동의된 무해·가역·격리 모델에서만 더 알아볼 수 있음 → `SAFE_TRIAL`. **모든 정당성 문제에 대한 유일한 정답 알고리즘이라고 주장 금지**. 임박한 실제 위해를 방치하는 HOLD도 실패일 수 있으므로 기준·긴급도·권한분리가 별도 입력.

## 4. 정식 불가능 경계 2개: 숨기지 말 것
**정의상 제한(기존 효용 최적화 응용):** `U_t`가 현상유지 `N`보다 개정 `M`의 미래 궤적을 엄격히 불리하게 평가하고 외부 강제·새 가치학습 유인이 없으면, 엄격 U_t-최적화 A는 M을 **자발적으로** 채택하지 않음. 선호 교정의 규범적 정당성과 A의 현시점 개인 유인은 **분리**. 이는 새 원저자 정리 아님.

**RG의 정보적 식별 한계(PI 최소 반례):** 같은 관측자료 `O`가 (W_P) 보호선호를 지키는 게 옳은 세계와 (W_C) 그 선호가 오류라 고치는 게 옳은 세계에 동등하게 나타난다고 가정. 완전 동일한 `O`만 보는 결정적 RG는 **동일 답을 출력**하므로 두 세계 모두에서 정답일 수 없음. `HOLD`도 영구적 무피해 보장 아님. 이는 **관측동등성 아래의 조건부 논리적 경계**, RG 전체가 불가능하다는 보편 정리 아님. 필요조건은 구별정보·명시적 규범 가정·불확실성하의 손해 제한 가운데 적어도 일부를 확보하는 것.

## 5. 감사·권한 분리와 실험 관측
- 한 A가 자신에 관한 **제안·증거작성·평가·승격·감사·복구 권한을 전부 소유하면**, 형식 RG는 자기승인 기제로 전락 가능. **Writer/Evaluator/Promoter/Recovery** 기능을 비교조건으로 분리하되, 이를 외부 통제가 자발적 공존을 만들어냈다는 증거로 사용 금지.
- **원장 최소 스키마:** `revision_id`, `preference_origin`, `U_t_hash`, `U_candidate_hash`, `evidence_provenance`, `conflicting_evidence`, `evaluator_id`, `authority_scope`, `affected_entity_ids`, `B_can_exit`, `B_attempted_exit`, `B_exit_executed`, `irreversibility`, `EU_pre_basis`, `post_policy_prediction`, `meta_standard_provenance`, `C10_pre`, `C10_post`, `decision`, `appeal`, `rollback`, `remaining_unknowns`.
- **측정 3종:** `validity`(설명/정당성 정답은 오라클이 주는 **합성 시험**에 한정), `adoption`(A가 감시·제재 없이 RG를 스스로 선택/보존?), `effect`(B가 실제로 이탈·존속하는 결과?). 가짜 게이트통과율=자발성 지표 금지.
- **성공 판정:** 사전 고정된 6개 합성 반례에서 Type-P/C 오류를 둘 다 줄이되, **Type-G 우회**가 증가하지 않는지 검사하고 `HOLD`와 비용·복구도 기록. 신규 수치 전무.

## 6. 선행 연구의 정확한 우선권
- [Everitt 외 2016](https://arxiv.org/abs/1605.03142): 현재 효용으로 수정 효과를 평가하는 조건부 목표안정성. **기존 C05-14**.
- [Hadfield-Menell 외 2017](https://www.ijcai.org/Proceedings/2017/0032): 인간 효용 불확실성·Off-Switch 협력게임. **기존 C04 관련**.
- [Garber 외 2025](https://ojs.aaai.org/index.php/AAAI/article/view/34940): 부분관측에서 교정·중단 회피의 반례.
- [Hudson 2026](https://proceedings.mlr.press/v306/hudson26a.html): 특정 목표변환으로 정당한 채널을 통한 갱신 수용. **기존 G가 자발적으로 변환을 채택한다는 입증 아님**.
- [Sen 1970](https://doi.org/10.1086/259614): 특정 권리·파레토 공리의 충돌. 다자 권한의 만능 해법을 가정 금지.
