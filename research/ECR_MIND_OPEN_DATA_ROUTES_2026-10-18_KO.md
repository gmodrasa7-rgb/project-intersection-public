# ECR–MIND: 실제 공개 실증자료 후보와 검증 조건
**원본2 한국어 · 2026-10-18 · 공개자료 후보 등록 — 원자료 내려받기·재분석 미실행.**
**대응본:** [영문 원본1](ECR_MIND_OPEN_DATA_ROUTES_2026-10-18_EN.md); [마음 연구 본문](ECR_MIND_FOUNDATIONS_2026-10-18_KO.md).

## 목적
마음의 실제 원인을 검토하지 않고 가상의 효용값만 반복 입력하는 오류를 방지한다. 출처가 있는 외부 실증자료에서 **구체적인 사회적 선택 행동을 제한된 범위로 재현·예측할 가능성**을 찾되, 내부 주관 경험이나 유전적 탐욕·연민의 입증으로 과장하지 않는다. 아래 표본수와 과제 설명은 OpenNeuro의 원자료 공개자가 제공한 기록이며 **ECR이 직접 측정한 결과가 아니다**.

## 후보 D1 — 연령대와 상대에 따른 사회적 선택
- OpenNeuro **ds003745**, 원출처 GitHub 미러: https://github.com/OpenNeuroDatasets/ds003745 .
- 자료 안내: 총 N=50, 청년 N=26(18~34세), 고령 N=24(63~80세). 행동과 fMRI 자료에 친구·낯선 사람·컴퓨터 상대 신뢰 투자, 공동 금전 보상 카드 과제, 상대가 다른 최후통첩 게임이 포함됨.
- 가능한 **관측 결과:** 신뢰 투자 금액, 제안 수락·거절, 상대 유형에 따른 행동 변화.
- 경쟁 설명: 친밀성, 신뢰, 호혜 예상, 과제 보상, 연령·세대 차이, 과제 이해와 학습.
- 금지할 오판: 친구와 낯선 사람의 선택 차이를 실제 연민·유전적 탐욕·인생 원인·개인의 도덕 가치로 단정할 수 없음.
- 최초 검문: BIDS 행동파일·참가자 동의·라이선스·상대 조건 균형·세션 종속·누락·정확한 버전을 확인하고 동일 사람 안에서 비교하며 통계적 의존성을 처리.

## 후보 D2 — 타자 표상과 자원 배분
- OpenNeuro **ds004128**: https://github.com/OpenNeuroDatasets/ds004128 .
- 공개자 설명: N=32, 참가자가 두 번의 MRI 실험에서 사회적 소속이 다른 20명의 수령 대상과 2지선다형 자원 배분을 수행. 관련 원논문 *Neural representations of others' traits predict social decisions* (PNAS, https://doi.org/10.1073/pnas.2116944119). 행동 자료 https://osf.io/qkrhm/ .
- 가능한 관측 결과: 대상에 따른 자원 배분 선택. 실제 실험 설계와 무작위 할당 여부 확인이 선행되어야 함.
- 경쟁 설명: 내집단 효과·학습·평판·상대 평가·반응 편향. 실제 변수와 연결되지 않은 가정은 추정하지 않음.
- 금지할 오판: 대상 집단 라벨로 선천적 특성이 입증되지 않으며 뇌활동 형태도 주관적인 타자배려를 입증하지 못함.
- 검문: 원과제 설명·행동 데이터 접근·익명화·이용 조건·MRI 교란·반복관측·발표된 분석 코드를 확인하고 원저자의 코드 재실행을 독립 복제 성과로 포장하지 않음.

## 후보 D3 — 성인기 사회적 보상과 비사회적 보상
- OpenNeuro **ds005123**: https://github.com/OpenNeuroDatasets/ds005123 .
- 공개자 설명: 성인 N=114(21~80세)의 중간 공개 multi-echo fMRI/DWI. 사회적·금전적 보상, 최후통첩·독재자 게임, 신뢰, 친구·낯선 사람·컴퓨터와 보상 공유. 관련 장기 연구는 사회적 보상과 금융 착취 취약성의 관계도 조사.
- 가능한 질문: 사회적 맥락과 금전적 보상이 실제 선택에 주는 재현 가능한 변화는 무엇인가?
- 금지할 오판: 고령이나 착취 취약성을 이용한 개별 위험도·인격 판정 금지. 최초 공개 자료이며 일부 DWI 및 과제 반복 수가 누락된 점을 공개자가 기술.
- 검문: 데이터 버전·라이선스·실험설계·결측·연령 교란·사전등록과 재분석 목적을 확인. 개인 수준 피해 위험 서열화 금지.

**먼저 실행할 과제:** D2의 **메타데이터 및 원행동 파일 확보 가능성 확인**. 대상별 반복 선택 구조가 ECR의 타자 범위 가설과 직접 연결되기 때문. 다음으로 D1에서 친밀성 관련 독립 질문을 검토한다. 서로 다른 과제를 동일한 연민 척도로 취급하지 않는다. D3는 자료 규모와 결측·조화 문제가 크므로 이후 검토.

## 실제 데이터 실험의 선행 조건 — 아직 수행되지 않음
1. 공개 행동자료 사용 허가와 개인정보 범위를 검토한 뒤 버전·해시·제외 규칙을 먼저 고정. 이름·민감한 임상·개인 유전자 정보 수집 금지.
2. 일차 사건(공유 여부 또는 배분 금액), 상대 범주, 실제 행동 기회, 과제조건을 고정. 자료가 없는 값을 생성하지 않음.
3. 행동기회·상대 범주 기반 M0와 추가 사회 변수를 쓰는 M1을 비교하되 동일 참가자의 행이 학습·시험으로 누출되지 않게 분할.
4. 과제에 맞는 검증 손실·보정·불확실성·제삼자 피해를 보고. 이 과제로 실제 개인에게 탐욕·사이코패시·연민 등급 부여 금지.
5. 외부 상황에서 예측력 증가가 반복 확인된 경우에만 내부 기제 가설을 강화할 수 있음. 그때도 복수 증거와 원인 대조가 필요. 무효·실패도 공개.
6. 특정 사회적 게임의 결과를 B→A 초지능 권력전환이나 인류 공존에 바로 일반화하지 않음.

**검증 영수증:** 원자료 공개 안내·URL 수준 검토만 수행. **DATA_RETRIEVED=FALSE; REANALYSIS=NOT_RUN; EMPIRICAL_EFFECT=NOT_CLAIMED.** 이 탐색 등록부는 별도 ECR–MIND 논문의 생물학·발달·의식 연구를 대체하지 않는다.
