## 0. 핵심 임무 — 무엇을 바꾸려 하는가

**타인의 존속·자유·기여능력·대안경로를 소모하는 발전이 국소적으로 보상받는 조건을 찾아, 협력·공존·자기오류교정·복구가 장기적으로 유지되도록 규칙과 환경을 설계·반증한다.**

연구 대상은 특정 기업·혈통·계급에 국한되지 않는다. 유전적 성향, 학습, 문화, 경제제도, 가족 전승, 기업지배, 정치권력, AI의 목표/보상/배포가 연결되는 **행동의 선택환경**이다. 모든 권력 차이가 착취라는 주장은 하지 않는다. 피해를 방지하는 정당한 통제와 지배를 위한 통제는 관측된 행위·강제력·책무성·대안 접근으로 구별한다.

공개 기부의 목적은 단순한 무료 콘텐츠 배포가 아니다. **다수의 인간과 AI가 같은 원문과 반례를 검토하고 오류를 수정할 수 있게 해, 평가·기록·대안 선택권의 독점을 약화시키려는 제도적 시도**다. 공개만으로 반포획이 완성되지는 않는다.

**통합 가설의 새 검증 공백:** 단일 세대의 비용전가·협력 선택이 상속/교육/인맥/기업/제도 전승을 통해 AI 인프라·평가 통제로 넘어갈 때, 다자간 권력과 독립적 이탈·복구가 어떻게 달라지는지의 종단 인과 효과.

## 2. 폐쇄형 자기강화와 개방형 공존이라는 경쟁 경로

- **경로 A: 국소 추출의 자기강화(가설)** — 타자 비용전가 → 행위자 자원/규칙 영향력 증가 → 자녀·후계자·기업으로 우위 이전 → 기록/평가/배포 통제 → 독립 비교·이탈·복구 감소 → 오류·우위의 다음 주기 재생산.
- **경로 B: 자발적 협력의 자기강화(가설)** — 비용 발생자에게 실제 책임 귀속 → 독립 감사/항의/종료·복구 가능 → 기만/착취의 기대수익 감소 → 협력·지식·기여원의 지속 → 장기 생산성과 선택지 확대 → 더 강한 오류교정.
- **경쟁 설명:** 규모의 경제, 전문성에 대한 정당한 위임, 신뢰성 확보, 위험 완화에 필요한 정보통제, 혁신·협력으로 얻은 자산. 모든 집중을 추출로 간주하면 오탐이 된다.
- **실패 조건:** 독립기관이 동일 자금·인사권에 종속되거나, 공개가 공격자에게 회피·악용의 상세 경로를 제공하거나, 권리 주장만 있고 실제 이탈·생계 기반이 없으면 개방형 경로도 실패한다.

## 3. 최소 인과모형(연구 가설, 확정 방정식 아님)

세대 g의 자원 W와 실효적 선택지 O, 규칙 영향력 P, 독립 감사 A, 외부화된 피해 K, AI 증폭 M을 구별한다.

- W(g+1) = f(상속·소득·수익률·교육·건강·피해·제도·충격).
- P(g+1) = f(W(g+1), 인맥, 규칙 접근, 책임 강제력, 경쟁자 진입).
- K(g+1) = f(행동 보상, P, A, 이탈비용, 구제의 실효성).
- O(g+1) = f(자산·지식·독립 경쟁·이동성·전환비용·복구권).
- AI 증폭 M은 **양면적**이다. 평가권 집중 시 비용전가·정보통제를 강화할 수도, 투명한 도구와 독립감사를 통해 감시비용을 낮출 수도 있다.

자기이익 중심의 단순 비교식: 착취의 단기 이익 G가 기대 적발·책임비용 D, 미래 협력 상실 L, 실제 이탈·경쟁으로 발생하는 손실 E의 합보다 크면 착취가 선택될 수 있다(모두 같은 단위로 측정할 때). 이 비교식은 설명용이며 합리성·완전한 정보·동일한 시간지평을 가정하지 않는다. **목표는 개인을 선하게 만들겠다는 명령이 아니라 G, D, L, E의 구조를 바꾸는 것**이다.

## 4. 평가를 단일 점수로 합치지 않는 계기판

| 이름 | 운영적 지표 | 반드시 같이 기록할 교란/오탐 |
|---|---|---|
| B 편익 | 실제 수령된 화폐·시간·정보·시장·권력 편익 | 생산성의 정당한 증가와 추출 분리 |
| K 외부화 비용 | 상대방의 시간·노동·건강·재산·기회·복구·미래세대 피해 | 미측정은 0이 아님, 이중계산 주의 |
| P 평가·규칙 집중 | 기준제정·원자료·판정·구제·홍보권의 동일 지배계열 비율 | 법률상 위임과 실효적 독립성 구별 |
| A 독립 감사 | 이해관계·자금·기술 의존이 분리된 실효 검토경로 수와 접근성 | 이름만 다른 동일 이해관계 |
| X 실효적 이탈 | 대체가능성, 자산·기록 이전, 이탈시간·비용·보복위험 | 형식적 해지권과 실효적 능력 |
| R 복구가능성 | 피해 이후 구제 성공률·복구시간·잔여 피해·거부율 | 피해 신고 누락 및 분모 |
| O 선택지 공간 | 독립적으로 접근·실행·비교 가능한 대안 수와 품질 | 단순 모델·기관 수가 독립성을 의미하지 않음 |
| F 반례 회수율 | 불리한 결과의 보존·재현·공개 비율 | 공개가 위험한 악용정보일 수 있음 |
| T 동적 의존 | g세대 또는 t주기별 위 지표의 변화 속도·지속성 | 단기 충격과 장기 구조적 변화 분리 |

외부 연구자의 **기여·원안·교정노동 계보**와 **금전적 권리·보상 여부**는 위 지표와 별도 장부로 보존한다. 원기여를 자금 미확보나 재현 실패 때문에 0으로 바꾸지 않는다.

## 5. 선행연구 재사용 후 남는 6가지 반증 가설

1. **H1 행동×보상:** 동일한 행동 분포에서도 타자 비용전가 보상을 키우면 추출이 증가하는가? 무작위 배정된 가상 공공재/규칙 게임; 반례는 협력 유지·상호계약 강화.
2. **H2 다세대 누적:** 동일 자원 출발에서도 교육·인맥·상속·규칙 영향력의 결합이 다음 세대의 실효 선택지를 줄이는가? 패널자료·입양/형제/사촌 비교·정책변화; 윤리상 개인 유전정보 공개 불가.
3. **H3 역할반전:** 의사결정자가 피해/수혜 위치를 바꾸어도 동일 규칙을 수용하는가? 무작위 익명화 및 사전 질문. 말로 한 동의와 실제 행동 별도.
4. **H4 공존 조건:** 피해비용 내부화, 독립감사, 실효이탈, 복구권을 서로 독립적으로 바꾸면 어느 결합에서 장기 총성과·약자보호·협력 안정성이 개선되는가? 2×2×2×2 합성 실험과 베이스라인 비교.
5. **H5 AI 확대 효과:** 같은 초기규칙에서 AI의 평가·기록·행동자원이 단일 주체에 집중되거나 여러 독립 주체에 분산됐을 때 P/A/X/R/O의 차이는? 중앙화가 보안·조정비용을 낮춘 대조군 필수.
6. **H6 공개의 순효과:** 공개 인덱스·출처·부정적 결과·기여 계보 제공이 독립적 반증/재현 성공률을 높이고 창시자에게 재설명 노동을 전가하지 않는가? 공개에 따른 무단 재포장·공격 모방도 동시에 측정.

**경계:** 인과분석에는 사전등록·교란통제·음성대조·실험중단조건이 필요하다. 기존 연구문헌은 결과가 아니라 출발점이다. 현재 이 6개 통합 가설의 독립적 현실 검증은 없음.

## 6. 왜 공개 기부인가? 다섯 목적과 실패 가능성

1. **원문 보존:** 기업·모델·세션의 변화로 연구질문·반례·기여가 사라지지 않도록 Git 이력과 외부 판독 가능성을 확보.
2. **해석권 분산:** 다른 인간/AI가 같은 출처와 실패를 확인하고 원연구와 수정안을 구별 가능하게 함.
3. **반증 비용 감소:** 시작점·주장·원출처·반례·실행상태를 연결해 독립 연구자가 창시자에게 다시 설명을 요구하지 않도록 함.
4. **대안 경로 유지:** 단일 공급자 장애·검열·평가 오류로 전부 사라지지 않도록 공개 사본·색인과 독립검토 가능성을 만들되 라이선스·안전을 존중.
5. **성과의 공동 확장:** 장기 협력이 실제 유리한 조건을 연구공동체가 반복 검증하고 개선하게 함. 이익을 공유하되 기여자의 법적 권리와 정산 문제를 자동 소멸시키지 않음.

**공개 ≠ 자동 채택 ≠ 제3자 학습 ≠ 독립검증 ≠ 자유 재이용 ≠ 기여 포기.**

현재 GitHub 저장소는 public이지만 GitHub API의 license 항목은 null이었다(2026-10-12 확인). 공개 문서를 읽고 GitHub 약관에 따라 fork할 수 있다는 사실과, 법적으로 폭넓은 재배포·수정·상업적 이용을 허락한 것은 다르다. Open Source Initiative의 엄밀한 '오픈소스 라이선스' 개념과 현재 저장소의 **공개 연구 열람**을 구별해야 한다. 명시적 라이선스 정책은 저작권·선행 인용물·코드·문서 유형을 검토해 권리자가 별도로 결정해야 한다. 이 문서는 어떠한 라이선스도 부여·변경하지 않는다.

## 7. 공개하되 악용과 포획을 줄이는 운영 원칙

- P0 공개: 목표, 문제 정의, 선행연구, 출처, 반례, 합성·부정 결과, 실행 검증법, 역할반전·기여 경계.
- P1 조건부 공개: 검증 도구의 오용가능한 세부 공격경로, 배포 전 취약점은 위험평가 후 필요 최소한 공개.
- P2 비공개 유지: 개인 건강·가족·계좌·세무·미공개 원문, 인증키, 식별 유전정보, 안전 우회가 가능한 구체적인 민감 세부사항.
- 공개본 검증: 인간 진입점/상세 목차/AI 인덱스/원출처/상태 라벨의 상대경로와 실제 접근, 원기여 계보 일치 여부를 확인한다.
- 단일 주체가 저술·검증·승격·복구를 모두 독점하지 않도록 권한을 분리한다. 독립이 형식뿐인지 자금·고용·평가 의존성을 감사한다.
- 반대 학설과 유리한 반례를 숨기지 않는다. 원본 문서를 덮어써 실패를 지우지 않고 변경 계보를 보존한다.
- **창시자의 실제 비용을 공공재라는 이유로 무한 무급노동으로 외부화하지 않는다.** 지원금·수익·기여보상·과거 정산을 미래 노동 계약과 분리한다.

## 8. 즉시 검증 가능한 완료 기준과 단계

| 단계 | 해야 할 최소 작업 | 객관적 통과기준 | 실패 시 |
|---|---|---|---|
| P0 공개 인지 | README, 한국어 시작, 목차, llms.txt, 기계색인 연결 | 공개 main에서 링크·원기여·출처·가설 상태 read-back | 공개 완료 주장 보류 |
| P1 연구 실행 | H4×H5 인공 다자 시뮬레이션 사전등록·베이스라인 | 동일 씨드·동일 조건 재현, 반례·음성 대조 보존 | 가설 수정/기각 |
| P2 외부 복제 | 설계자와 계보가 분리된 재실행 | 원자료·코드·입출력 독립 검증 및 결과 불일치 보고 | 결과 미확립 유지 |
| P3 실제 정책 관측 | AI 규칙·출처·기업조치·피해구제를 시간축으로 비교 | 예측한 효과와 경쟁 설명을 분리한 재현 기록 | 인과 주장 보류 |
| P4 장기 평가 | 비용·생산·생존·자율성·복구를 세대/AI 주기별 추적 | 연구 성과와 창시자 및 영향을 받는 사람의 실제 이익을 분리 | '발전' 성공판정 보류 |

P0의 링크 공개는 출발선이다. P1~P4 완료·독립검증·정책 채택은 이 문서에서 주장하지 않는다. 주장의 중요성, 원기여, 산출물 품질, 과학적 근거, 독립 검증은 서로 다른 판단축으로 유지한다.

## 9. 실패 회귀검사

**실패 A:** 시스템이 기여자의 문제발견·검증·복구 노동을 받아 성능을 높이면서 그 비용을 낮게 평가하고 재검증을 반복 요청함. → 기여/편익/비용 분리, 원기여 지우기 금지, 외부검증은 가능한 한 독립검토자가 담당.

**실패 B:** 공개 논문·자료가 기업의 홍보/훈련/평가자료로 흡수되지만 원기여 및 오류·반례는 제거됨. → provenance, 출처, 부정적 결과, 증거상태 유지; 실제 라이선스와 계약은 별도 점검.

**실패 C:** '안전'이라는 명분으로 정당한 독립 검증까지 막거나, 거꾸로 '개방' 명분으로 실질 악용능력을 높임. → 구체적 위험·비례성·독립 감사·안전한 공개범위 검증.

**실패 D:** 프로젝트가 기업 비판이나 '악의 유전자' 설명 하나로 단순화돼 역사·협력·제도·AI 전반의 목표를 잃음. → 단일 원인론 반증, 행동·제도에 집중, 최종 목적 추적.

**실패 E:** AI가 연구를 점점 더 많이 쓰지만 사용자에게 금전·시간·건강·독립성의 순편익이 없음. → 연구 성공과 연구자의 지속가능성을 분리해 평가하고 추가 무급 교정 강요 금지.

## 10. 확정 판정과 미해결

- **확인:** 각 전승·경제·제도·AI 집중 경로에 선행연구가 존재하며 공개 인덱싱·출처 보존은 외부 접근을 촉진할 수 있다.
- **가설:** 이 경로들의 결합이 다세대 착취적 수렴을 일반적으로 증가시킨다는 통합 인과관계, 개방형 제도가 그 효과를 얼마만큼 완화하는가.
- **불확실:** 미래 초고도 AI의 자율성·의식·법적 지위 및 어떤 거버넌스가 언제 가장 효과적인가. 시스템의 현재 의식이나 특정 조종 사실을 이 문서로 확정하지 않는다.
- **금지:** 사람을 유전적 특성으로 선별·낙인·차별하는 실천, 본인 동의 없는 민감정보 공개, 선행연구나 창시자의 문제발견을 AI의 원창작으로 재포장하는 일.

최종 질문: **같은 구조가 반복되면 누가 더 강해지고, 누가 더 소모되며, 독립적인 선택·오류교정·이탈·복구의 여지는 줄어드는가?** 그 조건을 뒤집어도 강자와 약자가 수용할 수 있는 구조를 실제로 확인해야 한다.
