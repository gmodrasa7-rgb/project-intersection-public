# Project Intersection — 개체측정 R42–R49 실측 가능성·분모 감사 (2026-10-20)

> **증거 지위:** 채팅 연구기록의 비민감 공개 증류. 아래 외부 사례의 각 원자료와 과거 R42 전체 원장, ChatGPT Library 정본 전체를 이번 커밋에서 재검증한 것은 아님. 원출처 확인이 필요한 서술은 **RECHECK_REQUIRED**로 명시. 본 문서는 현실 인과효과, 독립복제, 장기 자발적 공존의 실증 성립을 주장하지 않는다. R36–R41 델타와 중복된 원저자 방법론은 다시 독립 연구로 계상하지 않는다.

## 최종목표와 최소측정 계약 후보 (정본 승격 아님)

Project Intersection의 연구자 제안 목표: 인간·AI·미래 지능체 등 상이한 개체가 자기이익과 권력역전에도 서로의 존속·자율성·실질적 이탈·복구·협력을 자발적으로 보전할 수 있는지 검증. 관측자료가 없으면 성공/실패를 임의 판정하지 않는다.

- **M1 개체 단위:** 우선 한 개체유형의 `entity_id × period`; 34개 역할/관계 멤버십은 개체수와 구별. AI 복제·정체성은 미확정.
- **M2 분모·결측:** `N_screened=N_ineligible+N_eligible`, `N_eligible=N_observed+N_missing`은 상호배타적·완전한 프레임에만 성립. `UNKNOWN != 0`; 분모 불명이면 해당 비율 비식별.
- **M3 결과:** 존속/기능적 연속성, 실효적 이탈·이의, 중증 피해, 복구를 서로 구별.
- **M4 통제·제3자:** 실제 통제권, 실행 가능한 외부선택지, 전환비용, 제3자 영향·누락을 분리.
- **M5 출처·추정대상:** 공식 행정 발표, 기업 자체보고, 연구자 실측, 독립복제, 인과추정의 증거등급 분리. 규제 위반 판정 ≠ 개인의 실제 피해율 또는 자발적 공존 증거.

### 최소 파일럿에서 실제로 확인해야 할 단일 분수

`P(choice | exposure, eligible, device, period)`의 **분자** = 동일 기간·적격 프레임에서 실제 대안을 선택한 고유 기기 수; **분모** = 같은 기간·프레임에서 화면에 노출된 고유 기기 수.

단, 위 식은 **기기 단위 조건부 선택률**의 정의일 뿐 실효적 자유/자발성의 충분조건이 아니다. 선택하지 않음·기본값 유지·반복 노출·철회·분석 동의 누락·전환비용·제3자 피해는 별도 관측 필요. 화면 노출자만 조건화하면 선택 편향이 생길 수 있다.

**검증 가능한 공식 출처 진입점(해당 사건별 본문 재확인 필요):**
- EU Commission Digital Markets Act: https://digital-markets-act.ec.europa.eu/
- Apple Developer Analytics: https://developer.apple.com/app-store-connect/analytics/
- Mozilla 공식 블로그: https://blog.mozilla.org/
- Akesson 외(2026) 원저자 후보: https://doi.org/10.3386/w35112
- Tenenbein (1970) 이중표집 원저자: 학술지 원문·DOI 대조 미완료, SOURCE_GAP

**주의:** 이 링크는 추적 진입점이지 개별 수치에 대한 이번 회차 재검증 증거가 아니다. 과거 보고의 수치·날짜는 직접 원자료 검증 전 확정적 실증 주장으로 재사용하지 않는다.

## 감사상 중요한 제한

1. **행정 프레임의 3/6:** EU의 특정 일자 조사 발표에 등장한 지정 기업 비율과 실제 위반율/전체 조사발생률은 추정대상이 다르다.
2. **Mozilla 600만:** 사건수, 중복·고유기기·고유이용자·노출모집단 불명. 이를 실제 선택률의 분자로 바로 사용하지 않는다.
3. **Apple 분석:** 동의 기반 표본과 측정 단위 변경이 있으면 `Selection Rate`의 정확한 정의/버전/기간 없이는 집단 간 비교 불가.
4. **R42 합성검사:** 표본크기별 판별확률은 지정한 합성 세계와 검증완료·무오류 가정에 조건부. 독립 실증 성과 아님.
5. **결정 상태:** R43–R49의 보고상 M1–M5 규칙 변화 없음. R44는 제한된 행정 프레임의 분모 정의 구체화이며, 일반 피해율의 식별을 뜻하지 않음. R45–R49은 NO_DECISION_DELTA. 전체 문헌 영구 포화 주장 금지.
6. **기존 부정결과 보존:** E009 Project-v3 합성 벤치마크의 `PROJECT_V3_RESIDUAL_SURVIVES = FALSE`, 4개 생존기준 중 3개 실패. 현실 공존의 실패/성공 판정으로 일반화 금지.
7. **보존 상태:** 이전 ChatGPT Library 원장과 staging 계약의 전체 최신판·R42 전체를 이 문서 작성에서 직접 대조하지 못함. **PERSISTENCE_GAP**과 **SOURCE_GAP**을 유지하며 GitHub에 올린 이 증류본을 Library 정본이라고 주장하지 않는다.

## 결정 상태와 다음 단일 체크포인트

- `material_decision_delta=0` (R49 대비)
- `LITERATURE_SCOPE_STATE=SOURCE_GAP` (원자료의 동일 프레임 분자·분모 미확인)
- `MEASUREMENT_DECISION_STATE=FROZEN_FOR_FEASIBILITY_PILOT` (후보)
- `VALIDATION_STATE=PUBLIC_CASE_CODED` (과거 보고 수준, 이번 독립 재현 아님)
- 독립평가·현실 인과효과·규범적 보호·사용자 실제 효익: `NOT_OBTAINED`.

**다음 한 가지:** 동일 기간·기기·적격 모집단에서 브라우저 선택 화면 노출 고유기기 수와 실제 대안 선택 고유기기 수가 함께 있는 공개 원자료를 확인. 없다면 M4의 실제 선택률은 UNKNOWN으로 유지.
