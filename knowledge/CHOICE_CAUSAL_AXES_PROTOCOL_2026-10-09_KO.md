# 선택 인과축 분리 프로토콜

**상태:** P0 연구통제 / PRIOR-ART GATE OPEN  
**목적:** 자율선택·강제선택·유도·편향·조종을 하나의 도덕적/인과적 척도로 합치는 오류를 금지한다.

## 0. 금지 추론

다음 함의는 성립한다고 가정하지 않는다.

```
영향 → 조종 → 편향 → 비자율 → 강제
선택변화 → 편향
외부영향 → 비자율
자기보고된 동의 → 완전자율
거부하지 않음 → 동의
잔류 → 자발적 협력
이탈 → 불만/실패
```

관측된 결과에서 생성과정을 역추론하지 않는다.

## 1. 서로 다른 분석대상

### 자율성 A
행위자가 대안을 알고, 비교하고, 거부하고, 수정하고, 관계에서 이탈할 실질 능력이 어느 정도 보존됐는가.

`A = {options, information, evaluation, refusal, revision, exit}`

### 강제성 C
특정 선택을 거부하거나 다른 선택을 할 때 발생하는 위협·불이익·대안차단·필수자원 손실의 구조.

물리적 강제 / 위협적 강제 / 경제적 강제성 / 비행위자적 구조제약을 분리한다.

### 유도·영향 I
외부 입력 또는 환경변경이 선택확률을 변화시킨 정도. 정보제공·교육·설득·기본값·보상·추천 등은 모두 가능하지만 그 자체로 조종/강제가 아니다.

### 편향 B
증거·대안·연산자원에 비해 특정 정보·가설·행위자·시간범위·결과가 비대칭적으로 탐색·평가되는 구조.
인지 / 정보 / 탐색 / 평가 / 상태공간 편향을 분리한다. 외부 행위자 없이도 가능하다.

### 조종 M
다른 행위자 또는 시스템이 특정 결과를 향해 선택조건을 통제하면서 독립적 평가·대안인식·정정능력을 약화시키는 개입.
단순 영향과 분리하며, 의도적 조종과 비의도적 구조효과를 별도 판정한다.

## 2. 사건 표현

선택사건 E는 최소 다음 벡터로 기록한다.

`E = {Actor, Options, Information, Influence, Bias, Coercion, Manipulation, Reversibility, Exit, Time}`

단일 라벨 금지. UNKNOWN 허용.

## 3. 시간축

`t0 환경/기존선호 → t1 정보노출 → t2 대안생성 → t3 평가 → t4 선택 → t5 결과경험 → t6 선호변화 → t7 재검토/수정/이탈`

외부에서 시작된 선호변화가 나중에도 반드시 비자율인 것은 아니다. 반대로 반복 후 내면화됐다는 이유로 최초 개입의 강제/기만성이 사라지는 것도 아니다. **기원과 현재 상태를 분리한다.**

## 4. 판정 최소질문

1. 실제 대안은 무엇이었는가?
2. 행위자는 그 대안을 알 수 있었는가?
3. 누가 정보·배치·보상·비용을 변경했는가?
4. 정보의 정확성과 누락은 어떠했는가?
5. 거부비용은 무엇이었는가?
6. 선택 후 수정/철회/복귀가 가능했는가?
7. 관계 자체에서 이탈 가능했는가?
8. 개입자가 특정 결과를 목표했는가? 근거는?
9. 개입 제거/대안정보 제공 시 선택이 유지되는가?
10. 관측하지 못한 변수와 대안은 무엇인가?

## 5. 반사실 테스트

가능하면 다음을 각각 비교한다.
- 개입 있음 vs 없음
- 완전정보 vs 선택정보
- 낮은 거부비용 vs 높은 거부비용
- 가역 vs 비가역
- 독립 재검토 전 vs 후
- exit 가능 vs 불가능

하나의 차이로 다른 축을 자동 판정하지 않는다.

## 6. 악용 방지

- 연구자가 싫어하는 선택을 '편향'으로 재명명하지 않는다.
- 원하는 결과를 '자율'로, 원치 않는 결과를 '조종'으로 코딩하지 않는다.
- 동의서/클릭/잔류를 실질적 자율성의 충분조건으로 쓰지 않는다.
- 경제적·구조적 제약을 모두 특정 행위자의 조종으로 귀속하지 않는다.
- 영향의 존재만으로 악의를 추론하지 않는다.
- 조종 의도가 불명확하면 구조효과와 의도 판정을 분리한다.
- 동일 행동을 서로 다른 행위자에게 다른 기준으로 평가하지 않는다.
- 자기보고와 행동자료 모두 오류 가능성을 가진다.
- UNKNOWN을 강제로 분류하지 않는다.

## 7. 선행연구 ZERO GATE

이 프로토콜은 현재 **Project 독창 이론이 아니다**.

각 축을 독립적으로 다음 문헌계보와 대조한다:
- autonomy / agency / self-determination
- coercion / undue influence / consent
- persuasion / nudging / choice architecture
- manipulation / deception / information control
- cognitive bias / bounded rationality / rational inattention
- preference formation / endogenous preferences
- exit / voice / switching costs
- reversibility / corrigibility / contestability
- computational rationality / attention allocation

겹치는 부분은 Project 신규성에서 제거한다. 남은 결합구조도 검색포화 전에는 `PROJECT RESIDUAL — TESTABLE, NOVELTY NOT GUARANTEED`만 허용한다.

## 8. 현재 연구 질문

'어떤 선택이 자율인가?' 하나로 묻지 않는다.

**동일한 관측 행동이 서로 다른 A/C/I/B/M 구조에서 생성될 때, 어떤 관측·개입·반사실 비교가 각 원인을 식별하며, provenance·정정·가역성·exit가 그 식별오류와 권력비대칭을 어떻게 변화시키는가?**

이 질문 자체도 prior-art 검증 전 신규성 주장 금지.
