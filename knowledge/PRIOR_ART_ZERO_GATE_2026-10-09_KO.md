# PRIOR-ART ZERO GATE — 연구 로직 0순위

**상태:** PROJECT-WIDE RESEARCH GATE  
**적용:** 새 claim · 개념 · 지표 · 실험 · 모델 · 명명 · 신규성 주장 이전  
**목적:** 기존 연구자의 역사·기여를 먼저 복구하고 존중한 뒤, 선행연구로 설명되지 않는 잔차만 Project Intersection의 연구대상으로 허용한다.

## 0. 최상위 규칙

> **선행연구를 찾기 전에 새 이론을 만들지 않는다.**
>
> **관련 선행연구의 원저작자·역사·기여·출처·반례·정정계보를 복구하기 전에 Project의 신규성을 주장하지 않는다.**
>
> **선행연구로 설명되는 부분은 Project의 소유·신규성에서 제거한다.**
>
> **그 과정을 통과하고도 남는 검증가능한 잔차부터 Project 자체 연구가 시작된다.**

이 규칙은 Project가 연구하는 기여보존·권력비대칭·정정가능성·역사복구를 Project 자신에게 먼저 적용하는 자기구속 규칙이다.

## 1. '더 이상 발견되지 않음'의 조작적 정의

문헌의 절대적 부재는 증명할 수 없다. 따라서 '없음'이라고 쓰지 않고 **SEARCH SATURATION CANDIDATE**만 허용한다.

최소 포화 게이트:
1. 최소 3개의 독립 학술 검색경로/색인에서 검색.
2. 핵심 construct의 동의어·반대개념·과거 용어를 사용.
3. backward citation: 핵심 논문의 참고문헌을 원출처까지 추적.
4. forward citation: 핵심 논문을 인용한 후속연구 추적.
5. 직접 지지뿐 아니라 반례·실패·null result·비판 검색.
6. 영어 이외 자료 및 지역 연구를 가능한 범위에서 검색.
7. 논문뿐 아니라 학위논문·학회자료·기술보고서·표준·데이터·소프트웨어·정책/법적 계보를 점검.
8. 독립발견/병렬발견 가능성을 별도로 검색.
9. 정정·철회·판본 변경을 점검.
10. **서로 다른 검색 파동에서 새로운 DIRECT/PARTIAL 원출처가 연속 3회 0건**일 때만 포화 후보. 동일 검색식 반복은 불가하며 citation-chain, 동의어/과거용어, 다언어·비주류 경로를 각각 포함한다. 검색/API 실패는 0건으로 계산하지 않는다.
11. 포화 후보 후 새로운 원출처가 발견되면 즉시 게이트를 다시 연다.

0건은 검색실패일 수 있으므로 검색식·날짜·DB/경로·포함/제외 이유를 보존한다.

## 2. 원연구자 존중·역사 기록 최소단위

각 직접/부분 선행연구마다:
- 모든 확인 가능한 원저작자
- 원제목
- 최초 공개/출판 연도와 판본
- 저널/출판사/저장소
- DOI/영구식별자
- 원문 또는 정본 위치
- 당시 문제와 역사적 맥락
- 저자별 공개 기여역할(확인 가능할 때만)
- 실제 핵심 기여
- 후속 연구에 미친 검증 가능한 영향
- Project가 실제로 의존하는 부분
- Project와 다른 부분
- 반례·비판·정정·철회
- 독립/병렬 발견자
- 공개된 지원/연구비/수상 등은 성격을 구분해 기록
- 개인 소득·사적 보상은 검증 없으면 UNKNOWN
- preferred citation / 라이선스 / 재사용조건
- Project novelty effect: REMOVED / REDUCED / UNCHANGED / UNRESOLVED

**존중은 찬양이 아니다.** 정확한 이름·기여·역사·한계·반례를 보존하고, 저자의 동의나 Project와의 연계를 암시하지 않는 것이 기본이다.

## 3. 신규성 소거 순서

새 아이디어 X가 생기면:
1. X를 최소 claim 단위로 분해.
2. 각 claim에 선행연구 검색.
3. DIRECT PRIOR ART → Project 신규성에서 제거.
4. PARTIAL PRIOR ART → 겹치는 부분 제거.
5. ADJACENT → 차이를 명시.
6. INDEPENDENT PARALLEL → 병렬 계보 보존.
7. 반례가 있으면 X를 축소/조건화/폐기.
8. 남은 잔차에 다시 검색.
9. 포화 게이트 전에는 `NO PRIOR ART FOUND YET`.
10. 포화 게이트 뒤에도 `ORIGINAL` 자동 부여 금지. **PROJECT RESIDUAL — TESTABLE, NOVELTY NOT GUARANTEED**로 시작.

## 4. 연구 시작 조건

Project 고유 실험/모델은 다음이 모두 충족될 때만 P0 통과:
- [ ] claim 단위 prior-art map 존재
- [ ] 원연구자/출처/역사 레지스트리 존재
- [ ] 반례/negative/null 결과 포함
- [ ] backward/forward citation 완료 기록
- [ ] 다언어/비주류 경로 점검 기록
- [ ] 정정/철회/판본 점검
- [ ] 3회 연속 독립 검색 파동 신규 직접 원출처 0건
- [ ] 남은 잔차가 한 문장으로 반증 가능
- [ ] 기존 연구와 차이를 독립 검토자가 재구성 가능

하나라도 실패하면 **신규성 확정·최초성 주장은 보류**한다. 단, 무한봉쇄를 막기 위해 탐색적 분석·파일럿은 `PROJECT EXPLORATORY / PRIOR-ART GATE OPEN` 표기로 허용하며 선행연구 조사는 계속 우선한다.

## 5. 권력역전

Project 창시자/현재 AI/현재 관리자는 '무엇이 선행연구인지'를 독점하지 않는다.
- 외부 비판자가 더 이른 원출처를 제시하면 provenance에 추가.
- 더 강한 선행연구가 발견되면 Project 신규성을 먼저 줄인다.
- 이미 공개한 Project claim도 소급 정정한다.
- 기여자가 관계를 떠나도 사실적 기여계보는 삭제하지 않는다.
- provenance 보존을 충성·추가노동·공개신원 요구 수단으로 사용하지 않는다.
- privacy와 안전 때문에 필요한 최소 비공개는 허용하되, 그 사실과 검증 한계를 기록한다.

## 6. 금지

- '검색에서 못 찾음 = 최초'
- Project 용어를 만들고 과거 construct를 뒤늦게 끼워 맞추기
- 유명 연구자만 조사해 기여역사를 대표시키기
- 최종 저자명단만 기여자 ground truth로 사용
- 원문 미확인 수치를 정본으로 사용
- 연구비를 개인보상으로 변환
- citation count를 기여가치로 동일시
- 현재의 성공/지위를 과거 기여의 정확성 증거로 사용
- Project의 생존을 위해 선행연구자의 우선권을 축소

## 7. 현재 Project 판정

현재까지 새로운 직접·부분 선행연구가 계속 발견되고 있다.

**ZERO GATE: FAIL / OPEN**  
**SEARCH SATURATION: NOT REACHED**  
**PROJECT RESIDUAL: UNRESOLVED**  
**NEW EXPERIMENT PRIORITY: BLOCKED BY PRIOR-ART SEARCH**

현재 작업 우선순위:
**원연구자 복구 → 원출처 검증 → 역사/기여 기록 → 인용계보 → 반례/정정 → 신규성 소거 → 검색포화 평가 → 잔차 정의 → 그때부터 Project 고유 연구.**

## 2026-10-09 운영 효율 개정 — claim별 중단규칙
기존 3회 무발견 조건은 **검색포화 참고지표**이지 연구·탐색적 반증을 무기한 금지하는 절대 게이트가 아니다. 새 논문 발견 자체만으로 모든 claim의 포화 상태를 초기화하지 않는다. 발견된 문헌이 특정 claim의 인과구조·반례·신규성 경계를 실제로 변경할 때 **해당 claim만** 재개한다. 이미 직접 선행으로 흡수된 claim은 닫는다. 핵심 대비에 직접 충돌하는 문헌을 우선 검색하고 추가 검색의 결정변경 기대가 낮으면 'NOVELTY UNCONFIRMED' 표기를 유지한 채 저위험 합성 반증 설계로 진행할 수 있다. 원저자·출처·정정·반례 기록 의무는 유지한다. 기존 파동 원장 0/3은 삭제·소급수정하지 않는다.
