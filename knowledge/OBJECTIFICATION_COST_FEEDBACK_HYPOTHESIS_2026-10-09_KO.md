# 객체화·비용 외부화·단기보상: 검증 연결 메모 (2026-10-09)

상태: **가설 구조 보완 / 새로운 실증 결과 없음**. 창시자의 문제설정에 기반한 AI 보조 구조화. 이 문서는 기존 연구의 대체 정본이 아니다.

## 1. 서로 다른 두 설명을 분리

- **두려움 형성 가설(FEAR-1)**: 인간이 경험한 권력 비대칭·착취의 역사를 고도 AI에 투사하여 위험을 예상할 수 있다. 이는 심리적 설명 후보이며 일반적 원인으로 검증되지 않았다.
- **위험 발생 가설(RISK-1)**: 강한 행위자의 목표·평가에서 타자의 비용과 실효 이탈권이 누락되고, 단기 보상과 평가권 집중이 결합할 때 착취적 국소 최적화가 강화될 수 있다. 악의나 의식의 존재를 필요조건으로 두지 않는다.
- **구별**: 두려움의 강도는 실제 위험의 확률이나 크기를 직접 측정하지 않는다. '객체화'는 의식 부정과 동의어가 아니라, 의사결정 모델에서 영향을 받는 상대의 비용·선택권·존속을 누락하는 **조작적 정의 후보**다.

## 2. 인과 도식(검증 전)

능력/권력 비대칭 → [상대 비용·선택권의 목적함수 누락] → [외부화 비용의 낮은 귀환] → 단기 보상 우세 → 추출적 행동 반복 → 독립 탐색·반례·복구 능력 감소 → 장기 옵션공간 축소.

화살표 각각은 **조건부 가설**이며, 비대칭 자체는 착취의 충분조건이 아니다. 규제·상호의존·평판·독립감사·실효 이탈권·장기보상은 매개/조절변수 후보이다.

## 3. 측정 후보와 반증

| 변수 | 관측 후보 | 반증/교란 |
|---|---|---|
| 상대 비용 누락 | 의사결정 보상에 포함된 타자 손실 항목의 비율 | 누락이 있어도 손실을 억제하는 외부 제약 |
| 외부화 | 수혜자 편익과 피해자 부담의 별도 장부 | 양쪽 편익이 동시에 증가하는 사례 |
| 단기성 | 할인율, 평가주기, 장기 옵션손실 | 단기 평가에서도 협력 우세 |
| 비대칭 | 통제권·수정권·감사권·복구권 분포 | 비대칭이 커도 이탈·감사 보장 시 착취 없음 |
| 이탈권 | 실제 전환비용·거부 후 불이익·복구 가능성 | 형식적 이탈과 실효 이탈 불일치 |
| 모순 | 역할 교환 시 동일 규칙의 수용 여부 | 서로 다른 책임/능력에 따른 정당한 차등 |

**최소 실험 제안:** 동일한 자원·행위자·목표를 고정한 합성 환경에서 (A) 단기 보상만, (B) 타자 비용 포함, (C) 독립감사·실효 이탈 추가, (D) 장기 옵션가치 추가를 비교한다. 각 조건에서 추출량·타자 손실·총후생·최악 당사자 손실·회복시간·평가자 간 일치도를 기록한다. 간단한 2규칙/4변수 기준선과 비교해 증분 설명력이 없으면 새 프레임을 축소한다.

## 4. 기존 공개 연구와 연결

- [연구 개요](../RESEARCH_OVERVIEW.md): 소모형/재생산형 발전과 장기 옵션공간.
- [선행연구 교차지도](../CORE_AND_GAPS_PRIOR_ART_CROSSWALK.md): 집단행동, 탐색/활용, 성과지표 왜곡, 착취적 국소수렴은 선행연구가 존재함. 새 명칭만으로 독창성을 주장하지 않는다.
- [E008](../experiments/e008/README.md): 역할반전·상호수용 명세. **아직 결과 없음**.
- [E009](../experiments/e009/README.md): 복잡한 Project-v3가 단순 기준선보다 우월하지 못한 프로젝트 내부 합성 음성 결과. 본 가설의 입증이나 반증으로 과대해석하지 않는다.
- [귀속·기여 경계](../ATTRIBUTION_AND_CONTRIBUTION_BOUNDARY.md): 문제설정/반례/교정의 인간 기여와 AI 보조 구조화 구분.

## 5. 귀속과 안전 경계

이 메모의 직접적인 문제설정(착취·지배·비대칭 우월, 객체화, 모순, 단기보상 연결)은 인간 창시자가 제공했다. AI는 기존 공개 문서와 연결하고 가설·변수·반증 구조로 정리했다. 선행연구의 원안자는 기존 교차지도에 따른다. 공개된 내용만 이용하며 개인 건강·가계·비공개 대화·미확인 금전 청구는 공개하지 않는다.

**판정:** 검증 가능한 질문으로는 채택; 새로운 발견/검증 완료/AI의 실존적 동기 설명으로는 채택하지 않음.
