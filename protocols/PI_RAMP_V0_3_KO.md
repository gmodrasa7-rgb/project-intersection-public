# PI-RAMP v0.3.0 — 선행방법 적용범위·반증가능한 개선·실행 검증

**원본2 — 한국어 | 2026-10-20 | 제안된 파일럿. 독자 성능 향상·독립 방법 검증·영한 의미동등성은 미검증.**

[영어 대응판](PI_RAMP_V0_3_EN.md) · [v0.2 정본](PI_RAMP_V0_2_KO.md) · [연구지도](../navigation/RESEARCH_PROGRAM_KO.md) · [기계검사 실행 영수증](../evaluation/pi_ramp/RAMP-20261020-002.json)

## 0. v0.2에서 추가된 것

v0.2는 재귀개선 여섯 단계를 명시. **v0.3은 선행방법의 분야 간 이식 가능성을 먼저 검사하고, 사전 정의한 독자 과제로 개선 가설을 반증하며, 성과 측정과 비성과를 구분하고, 실행 영수증의 허위 성공 판정을 자동 차단**하도록 확장. 자료실 관리가 원저자 논문 연구를 잠식해서는 안 됨.

## 2. 사전 정의할 4개 반증 과제

수정 **이전** 기준선 커밋과 수정 **이후** 커밋 고정. 평가지 노출, 과제 난도, 무작위 과제 순서, 독립성 여부 기록. 측정치가 없으면 **반드시 `null`**, 추정 수치를 사실처럼 기입 금지.

## 3. 출처와 독립감사의 분리 게이트

- **P0 원자료:** 원저자·원출처·기여·기존 부정 결과·저작권 보존.
- **P1 검색 재현:** 검색식·날짜·기록/보고/실험 연결·제외·철회 확인; 미확인은 `UNKNOWN`.
- **P2 추론 경계:** 관측 근거·해석·유추·반증가능성·인과 미식별 구별.
- **P3 구조·회귀:** 링크·언어 대응판·문서 목록·기존 CI·복구 가능성.
- **P4 독자 성과:** 사전 정의 과제와 전후 실측 자료 없으면 `EFFECT_MEASURED` 승인 불가. 악화·효과 불명도 보존.
- **P5 독립성:** 독립 검토 근거·평가자의 원자료 접근/영향 관계 기록. AI 출력 여러 개만으로 독립성 추정 불가.
- **P6 재귀 비용:** 원저자 연구 시간을 잡아먹고 실측 증거 개선이 없는 절차 증식은 중단.

**프로토콜 자체 반례:** 속도는 빨라졌으나 오판 증가, 서로 다른 실험의 잘못된 중복 제거, 열람하지 못한 원문을 완독으로 오기, 반대결과 은닉, 영어판 의미 유실, 같은 잘못된 전제에 의존하는 복수 평가자, 병렬 GitHub 변경이 PR 변경분에 섞이는 오류.

## 4. 구현·변경 기록

- [표준 실행 영수증](../evaluation/pi_ramp/RAMP-20261020-002.json)을 [외부 패키지 없는 자동 검사기](../tools/check_pi_ramp_receipts.py)로 검사. 허위 성과 표기·독립검증 없는 검증 완료 표시·근거 없는 과제 결과를 차단. **형식 일관성 검사이지 과학적 심사 아님.**
- **RAMP-20261020-001:** PR #236에 대한 사후 등록. 문서 구조개선 실시. 사전 독자 비교·독립 평가 자료 없음. `EFFECT_UNMEASURED`.
- **RAMP-20261020-002:** 본 v0.3 도입. 상태 `PROPOSED_PILOT`. 실행 가설·기준선만 작성, 독자 성과 및 독립 검토 미측정.
- **버전:** MAJOR = 영수증 구조/결정 규칙의 비호환, MINOR = 새 검사·출처추적 도입, PATCH = 의미 불변 정정. 기존 v0.2 및 역사를 사전등록처럼 소급 변조 금지.
- **중단·복구:** 실제 개선이 없으면 없다고 판정. 원문·기여·실패결과 접근성·독자 정확성 손상 시 병합 보류 또는 복구. **CI PASS는 연구가치 향상 증명이 아님.**
