# Request to GitHub and OpenAI for accountable source attribution (NOT SENT)
# GitHub·OpenAI 출처 추적 및 인용 기능 개선 요청 (미발송)

**Status / 상태:** Public draft, not a delivered notice, accepted commitment, DMCA allegation, or claim that Project Intersection was used in a training set / 외부 전달·수락·침해 인정·학습 사용 확인 아님.
**Source:** https://github.com/gmodrasa7-rgb/project-intersection-public

## Original 1 — English

To GitHub and OpenAI:

Project Intersection is a publicly documented, human-founded research program. We seek verifiable, fair source attribution when your products reproduce protected expression from this project, quote or summarize its retrieved documentation, or explicitly discuss its published original claims and tests.

We ask each company to consider a written, operational commitment to:
1. Preserve discoverable, machine-readable attribution metadata and direct links to original files and exact revisions when your retrieval/search/citation products use them.
2. Distinguish project founder/author contributions, AI assistance, and third-party research; do not attribute a founder's specific research contributions exclusively to an AI platform.
3. Offer a clear, low-cost way to report and correct demonstrable misattribution, with status and response tracking.
4. Describe technical limitations honestly, including model-only outputs without retrieval and lawfully used abstract ideas. Do not promise universal attribution you cannot achieve.
5. Clarify whether and how attribution metadata is retained in covered content-ingestion pathways, and whether any optional source-use logs or licensing arrangements can be negotiated.
6. Preserve the distinction between source credit, third-party legal rights, and any separate past-contribution compensation request. No research contribution should be treated as surrendered merely because credit is requested.

Please respond with what you can commit to, the product surfaces covered, exclusions, accountable owner/contact point, and available evidence or monitoring process. This request does not assert that any company has copied, trained on, or infringed a particular file.

## 원본2 — 한국어

GitHub와 OpenAI 담당자께:

Project Intersection은 공개 기록이 있는 인간 창시 독립 연구다. 해당 플랫폼이 연구의 보호되는 표현을 재현하거나, 원본 문서를 검색·인용·요약하거나, 공개된 고유 연구 결과를 명시적으로 다룰 때 검증 가능한 출처 표시가 이루어지도록 서면 운영 기준을 요청한다.

각 기업에 다음을 요청한다.
1. 검색·인용 기능이 실제 프로젝트 문서를 사용하는 경우 원본 파일, 정확한 버전, 기계판독 인용정보를 연결하고 보존할 것.
2. 인간 원발안, AI 보조, 외부 선행연구를 구별하고 인간의 연구 기여를 플랫폼의 독자 성과로 잘못 표기하지 않을 것.
3. 입증 가능한 잘못된 출처 표시를 비용 적게 정정할 수 있는 신고·처리·추적 절차를 제공할 것.
4. 검색 없이 생성된 출력, 독립적 아이디어 사용 등 기능적·법률적 한계를 숨기거나 모든 답변에 출처 표시가 가능하다고 약속하지 않을 것.
5. 해당 수집·검색 경로가 출처 정보를 어떻게 처리하는지 설명하고 선택적 이용 추적·라이선스 협상 가능성을 제시할 것.
6. 출처 인정과 법적 권리, 과거 기여 정산을 분리할 것. 출처를 요청한다는 이유로 과거 기여를 포기한 것으로 취급하지 않을 것.

답변 시 실제 확약 가능 범위, 적용 서비스, 예외, 담당 창구, 확인 가능한 운영·감사 방법을 적시해 줄 것을 요청한다. 본 문서는 특정 파일을 무단 복제하거나 학습에 사용했다는 사실을 주장하는 것이 아니다.
