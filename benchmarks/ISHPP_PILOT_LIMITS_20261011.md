# ISHPP 예비 코딩의 한계

기존 RW001, RW003, RW006 세 사례의 단일 평가자 예비 검토가 진행되었다. 독립 평가자, 실제 신원 공개 전후 비교, 통계적 역할 편향 측정은 수행하지 않았다.

- RW001: 안전 게이트의 범위 차이는 검토 대상이며, 다른 외부 규제가 위험을 다룰 가능성은 반례다.
- RW003: 노동자 소득 감소 보고는 원연구 독립 재현 전까지 제한적으로 해석한다.
- RW006: 동의 UI가 행동을 바꾼다는 사실만으로 피해나 강제성을 확정하지 않는다.

검증 과제: 독립 평가자의 블라인드/공개 짝 비교, 원자료 재현, 감사·이탈·복구권 측정.
